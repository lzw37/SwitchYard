
# 驼峰设计与溜放仿真使用说明

本文对应当前 `/hump` 页面。驼峰模块保留原有按钮、标题、工具栏和面板样式；纵断面侧面板使用原有的展开与收起方式。账号、语言等公共功能见[通用使用指南](User-Guide.md)；安装运行见[项目说明](../README.md)。

## 1. 开始前：实例与数据关系

登录后，在页面左上角选择一个启用的驼峰实例。普通用户处理自己的实例；管理员还可通过右上角用户菜单进入“实例管理页面”管理实例及所属用户。

“计算实例管理”按钮打开实例列表，可新建、复制、修改名称和启用状态、删除实例。复制时填写新名称，编号由系统生成。新建空实例后仍需按下面的步骤准备数据；为了比较方案，也可复制已有实例再修改。停用实例后，它不会出现在工作页的实例选择框中。

几个容易混淆的对象如下：

| 对象 | 内容与用途 | 编辑入口 |
| --- | --- | --- |
| 驼峰实例 | 一组驼峰设计数据的容器 | 左上角“计算实例管理” |
| 溜放线 | 平面控制点、区段、道岔、减速器 | “平面展开图”的溜放线管理 |
| 车辆参数 | 车型、尺寸、质量、轴数等 | “计算参数”上半部分 |
| 运行工况 | 速度、风、空气密度、温度等；界面标题为“计算条件” | “计算参数”下半部分 |
| 纵断面方案 | 控制点位置和高程构成的纵断面 | “纵断面设计”的方案管理 |
| 计算条件 | 车型、运行工况、溜放线、纵断面方案及减速器状态的组合 | “纵断面设计”的计算条件管理 |
| 检算方案 | 纵断面、溜放线、推峰速度和钩车顺序的组合 | “车辆溜放检算”的方案管理 |

建议按“平面展开图 → 计算参数 → 纵断面设计 → 车辆溜放检算 → 仿真”的顺序完成一个实例。更换实例时，上述数据也随之切换。

## 2. 编辑平面展开图

1. 在“平面展开图”页选择溜放线。没有可选项时，打开溜放线管理，新建并保存一条溜放线。该管理窗口也提供重命名、复制和删除。
2. 在下方控制点表中添加或插入控制点，填写编号及 X 坐标。控制点修改后，使用区段表旁的“更新”按钮更新区段，再核对起终点、长度、曲率、方向及位置参数。
3. 切换下方的道岔和减速器页签，添加设备并设置绑定位置、类型等参数。设备引用的控制点和区段应来自当前溜放线。
4. 对照上方图形检查布置，点击顶部“保存”。“加载”按钮重新读取服务器上的平面数据，使用前应保存需要保留的修改。

图形与下方表格按原有布局显示。选择图中对象时，相关表格行会联动显示，便于定位和核对。

## 3. 准备车辆与运行工况

进入“计算参数”页：

- 在“车辆参数”中新增或编辑车型，填写车长、自重、载重、迎风面积、轴数、车辆标签和重力参数，按行保存。总质量由车辆数据计算。
- 在下方“计算条件”中建立运行工况，填写名称、峰顶/坡上/调车场速度、风速与风向、空气密度和温度，按行保存。

数字的单位以字段表头为准。页面输入速度使用 `m/s`；不要直接填入 `km/h` 数值。车辆和工况只是基础数据，还需要在纵断面设计页中组合成可计算的条件。

## 4. 建立纵断面方案并计算

1. 进入“纵断面设计”，打开纵断面方案管理，新建或复制方案并选中。方案管理支持修改名称和删除；界面会保留至少一个方案。
2. 在绘图区底部的加点线上移动鼠标，点击跟随位置显示的“+”添加控制点。空方案首次加点会建立初始点；继续补齐需要的控制点。
3. 上下拖动图中的控制点调整高程；按住 `Alt` 开始拖动可调整水平位置。也可打开右侧“数据”面板，在控制点表中精确填写位置和高程。右键控制点可删除节点。右侧区段表显示对应的长度、坡度及高差。
4. 打开“计算条件”管理，新增一项，选择已保存的车型、运行工况、溜放线和纵断面方案。通过“减速器状态”设置所用减速器、启用状态和输出等参数，保存条件。
5. 选中方案和计算条件，检查顶部显示的车型、溜放线及工况摘要。手工表格编辑后先点“保存”，再点“执行计算”。
6. 使用开关显示初始动能、阻力能高、动能高和制动能高曲线；通过缩放设置调整横纵比例。右侧能高数据表可用于核对位置、能高与瞬时速度；点击阻力区域可查看指定位置的阻力详情。

图中控制点的增删、拖动完成后会触发保存；条件齐备时还会重新计算。手工在表格中输入不等同于完成保存。以保存/计算提示和更新后的结果为准，遇到失败时使用顶部按钮重新保存或计算。

左右两侧的箭头可展开或收起工具、数据面板，面板沿用原有宽度。左侧开关控制减速器、数值及光标标签等显示，显示开关不会修改基础设计参数。

## 5. 车辆溜放检算

1. 在“车辆溜放检算”中打开检算方案管理，新建检算方案。
2. 选择纵断面设计方案和溜放线，设置推峰速度，并按所需顺序选择钩车。钩车选项来自该设计方案下已建立的计算条件。
3. 点击“执行检算”。程序先保存当前检算配置，再计算并刷新速度—距离、时间—距离曲线。
4. 查看曲线及时间图中的间隔标注。可切换曲线标签、关闭不需要的标签，或将单张图表展开查看。

若提示“配置保存成功，但刷新结果失败”，应检查引用数据并重新检算，不能仅凭配置已保存就认定计算成功。修改基础工况、车辆、平面或纵断面后，也应重新执行检算以查看对应结果。

## 6. 二维与三维仿真

“车辆溜放仿真”和“3D 溜放仿真”使用检算方案。选择方案后，页面读取纵断面并请求运行时间和速度数据，生成可播放的车辆轨迹。

- 播放按钮提供开始、暂停、结束、前一秒、后一秒及复位。
- 倍速滑块范围为 `0.25×–3×`；进度滑块用于定位时刻，旁边显示进度和仿真时钟。
- 二维页显示断面上的车辆位置、顺序、车型和速度。
- 三维页还可旋转、平移和缩放视角，使用“复位视角”“跟随”和“显示标签”控制观察方式。

未生成轨迹时，播放按钮不可用。返回检算方案检查钩车、运行条件和引用数据后再选择方案加载。三维页面展示的是计算结果的示意场景，车辆模型和部分显示尺寸经过可视化处理，不用于量取工程尺寸。

## 7. 常见问题

| 现象 | 处理方式 |
| --- | --- |
| 实例下拉框为空 | 确认已登录、账号可访问该实例，且实例为启用状态；可在实例管理中刷新列表。 |
| 纵断面没有曲线 | 确认方案有控制点、已选计算条件且其引用完整；执行计算并打开相应曲线开关。 |
| 找不到钩车选项 | 先在纵断面设计页为当前方案建立并保存计算条件，再返回检算页选择。 |
| 提示缺少引用或计算依赖 | 按提示中的对象名称/编号检查车型、工况、溜放线、纵断面方案、计算条件及检算方案，补建数据或重新绑定；不要只重复点击计算。 |
| 仿真没有轨迹 | 确认检算方案有有效钩车，运行时间与速度计算成功，且纵断面可读取。 |
| 切换页签后数据发生变化 | 页面会重新读取相关数据；离开前保存表格编辑，返回后确认当前实例和方案。 |

## 附录：历史设计规范备注

以下保留原文档对 TB10062-99《铁路驼峰及调车场设计规范》的设计备注，便于追溯项目早期设计依据。这里未核验该版本是否现行、是否适用于具体项目，也未逐条核验程序实现的覆盖情况；引用这些条目不表示程序已经完成相应规范校核。

原“驼峰溜放部分平面”备注：

- 5.3.4 曲线半径不应小于 200 m；平面连接困难时，最后分路道岔后的连接曲线可个别采用 180 m。
- 5.3.4 同向或反向两曲线之间设置不小于 15 m 的直线段；困难条件下不小于 10 m。
- 5.3.5 第一分路道岔岔前直线段长度不应小于 1.8 m；困难条件下不小于 0.5 m。
- 5.3.6 峰顶至第一分路道岔基本轨轨缝间的最小距离为 30–40 m。
- 5.3.7 设两级制动位时，第一制动位设于第一分路道岔和第二分路道岔之间。
- 5.3.7 溜放部分减速器设在直线上，始末端至相邻曲线的最小直线段长度满足结构安装要求。
- 5.3.8 调车场内设有减速器时，入口距最后分路道岔后警冲标不宜小于 42 m；减速器前方直线段长度不小于 14 m。

原“驼峰溜放部分纵断面”仅列出“坡度坡段要求”“变坡点位置要求”两个待补充主题，没有给出完整校核规则。
