# 通过能力使用指南

本文按当前程序界面说明从站场建模到计划分析的操作流程。环境安装和服务启动见[项目说明](../README.md)，作业过程的字段、约束与接口见[作业过程编排](../docs/operation-process.md)。

## 界面与数据层级

进入「通过能力」后，先在顶部选择计算实例，再在各功能页选择站场方案。「作业过程编排」和「列车模板」属于车站方案，供方案下的各个计划共享，尚无作业计划时也可使用。具体列车作业计划、求解和仿真还需要选择该方案下的目标作业计划。切换页面后应核对当前选择，避免把不同方案或计划的结果放在一起比较。

除独立车站布置图控件外，主要操作使用小圆形按钮。悬停查看操作名称，键盘聚焦也可获得提示；本文提到的「保存」「刷新」「新增」等通常指对应圆形按钮。名称、表格字段和当前选项仍保留文字，页面不再重复展示模块标题。

功能面板之间的细分隔条可以拖动：竖条左右调整宽度，横条上下调整高度。进路设计、计算参数、作业过程编排、列车列表与明细、模型求解、2D 仿真及 3D 底部占用图按各自布局提供分隔条。聚焦统一分隔条后可用方向键调整，按住 Shift 加大步长；Home / End 调到范围边界，Enter 或双击复位。尺寸受面板最小可用空间限制，部分窄窗口布局使用滚动查看内容。

右上角的 EN / 中按钮切换界面语言。用户填写的实例名、方案名、列车名及模板内容属于业务数据，不会随界面语言自动翻译。

| 页面 | 当前用途 |
| --- | --- |
| 车站布置图 | 编辑并保存站场几何、拓扑和设备 |
| 进路设计 | 配置进路起终点，搜索、生成和维护进路及直接妨碍区段 |
| 计算参数 | 设置进路对轨道电路区段的占用时间偏移 |
| 作业计划 | 过程编排、列车模板、列车计划、计划图及能力分析 |
| 模型求解 | 连接 CapacityAgent，预览输入、提交求解、管理求解预设 |
| 3D / 仿真 | 分别以三维、二维方式回放已有作业计划 |
| 结果分析 | 独立页签目前仍是占位；实际分析在「作业计划」内 |

## 1. 准备实例与站场方案

打开顶部「实例管理」，创建或选择有权限使用的能力计算实例。主界面的实例选择器显示启用的实例。进入「车站布置图」，选择或建立站场方案，再导入或编辑布置图。

站场布置图是独立复用控件，保留自己的编辑工具栏。可从 DWG 提取图形，也可手工画线；导入图形后仍需检查节点、设备绑定、轨道电路区段及进路所需的信息，再保存方案。复用控件的接入方式见[站场模块说明](../SwitchYard.StationLayout/README.md)。

在「显示样式 → 文字 → 轨道电路名称」调整区段名称的字号、字体和颜色，点击「保存」后随站场方案保存；仿真及其他二维站场视图加载该方案时使用同一设置。

### 拓扑整理

几何线段并不自动等于完整的铁路拓扑。当前代码提供自动打断、生成节点和合并近邻节点等整理操作：

- 两条线段在内部相交时，在交点处分别打断。
- 线段 A 的端点落在线段 B 的内部时，打断 B；A 不需要在自己的端点再次打断。
- 端点距另一条线段小于自动打断容差时，在该线段的最近投影点加入打断点。应继续检查端点吸附及节点连接，不能仅凭图上接近判断已经连通。
- 自动生成节点根据所有线段端点建立 Node，并写入 Link 的起终点关联；同坐标的已有节点尽量复用。
- 自动合并节点按距离容差合并近邻节点，并更新边、相关设备和曲线的引用。

Node 表示拓扑节点，Link 表示相邻节点之间的边，Cell 表示轨道电路区段，StationRoute 表示进路。过程编排中的备选股道使用现有 Link，因此需要为可用的停留股道填写名称。

道岔、信号机、绝缘节、车挡等有各自的设备属性和节点绑定。删除绑定设备的节点时，界面要求确认设备的同步删除。拓扑重建或合并可能影响已有区段、设备和进路，完成后应检查相关提示并复核这些数据。

旧版草稿中的固定线宽、自动删除短边、按节点度数自动合并或禁止删除，以及仓库、警冲标等设备设想，不作为当前操作规则；以编辑器实际提供的对象、属性和校验为准。

## 2. 配置和检查进路

进入「进路设计」，选择同一站场方案：

1. 在「进路起终点配置」维护节点绑定、类型和标签，也可按已有信号机及车挡自动配置。
2. 新建进路并点选起终点，检查搜索到的候选路径；也可选择多组起终点批量自动生成。
3. 核对类别、描述、途经节点、边、道岔、信号机及轨道电路区段，保存进路。
4. 检查或生成直接妨碍轨道电路区段，确保后续占用参数与站场实际一致。

进路列表支持筛选和批量删除。没有搜索结果时，先检查拓扑连接、道岔及起终点配置。作业过程中的接车、发车、调车和机车移动按相应进路类型选择候选，错误的类型会导致候选不可用。

## 3. 设置计算参数

进入「计算参数」，从左侧选择进路，在布置图与占用时间图中核对区段，右侧维护各区段的开始、结束占用偏移。可创建占用时间记录、编辑数值、统一偏移，也可按进路类型批量设置。单条进路编辑完成后使用「保存」；占用时间图支持拖动端点调整偏移。

这些偏移用于把作业时刻转换成轨道电路区段的占用时段。应同时检查实际途经区段和直接妨碍区段；缺失或不准确的配置会影响计划图、冲突判断及后续能力结果。

「牵引计算」当前展示前端样例生成的速度—距离、时间—距离及占用时刻，不是接入正式牵引模型后的计算结果，不能据此代替实际占用参数标定。

## 4. 建立作业计划

进入「作业计划」，选择站场方案，即可维护方案共享的作业过程模板和列车模板；这两个栏目不显示作业计划选择器。切换同一方案下的计划会保留模板、展开状态和过程编排草稿，不同方案的模板相互隔离。需要生成具体列车作业时，进入「列车作业计划」，通过「作业计划管理」新建或选择目标计划。

复制计划不会复制共享模板库，计划改名／改 ID 不会修改共享模板，删除某个计划也不会删除共享模板。旧版按计划保存的模板会自动在事务中迁移到所属方案；ID 冲突时保留全部模板，并同步处理关联作业及必要的来源引用。

| 方式 | 适用情况 | 生成行为 |
| --- | --- | --- |
| 列车模板 → 自动生成 | 使用按顺序排列的传统作业 | 使用方案共享模板，按已有规则重建选定的目标计划 |
| 作业过程 → 列车模板 | 需要把活动转换成传统模板继续编辑 | 在方案中新增共享模板，无需作业计划；仅映射传统字段，部分过程约束不能完整保留 |
| 作业过程 → 列车作业计划 | 需要保留事件图、时长范围、间隔和资源约束 | 从方案共享过程读取约束，按指定数量与时间范围向目标计划追加完整列车，并保存独立过程快照 |

在「作业过程编排」中创建活动、事件、次序和锚，配置备选进路或停留股道，校验并保存后才能用于生成。界面从左到右为编排图、属性和对象列表；右侧列表可以隐藏，分栏可拖动调整。

过程模板使用相对分钟数；传统作业最小时长与求解输入使用秒。批量过程生成支持 1–1000 列车、本批最多 20000 个活动，时间范围最多跨 7 天。它会满足单列车的过程约束，但初始排布并不替代跨列车占用冲突优化。

生成后在「列车作业计划」检查车次、作业时刻和资源。展开左侧列车后，右侧移动明细在名称后显示每一项移动的「开始时刻」「结束时刻」，支持跨日和秒数，没有相应时刻时显示「—」，并沿用移动的编辑、保存逻辑。可搜索车次、名称、类型并批量删除已保存的列车。绑定过程的列车通过「过程约束」查看快照；旧明细表不能单独增删、重排其活动或改写约束字段。修改源过程不会自动更新已生成列车，需要重新生成。

### 导入 CellOccupancy CSV

在「列车作业计划」工具栏点击「导入 CellOccupancy」，选择 UTF-8 CSV 文件（不超过 5 MB、50,000 条占用记录）。文件需要以下六列：

```csv
TrainID,MovementID,MovementType,CellID,OccupancyStartTime,OccupancyEndTime
C2551,0,Arr,1G,02:09:00,02:14:00
C2551,1,Dw,1G,02:14:00,02:30:00
C2551,2,Dep,1G,02:30:00,02:33:00
```

上例仅展示列格式；实际文件应包含每项作业占用的全部 Cell。同一列车、同一 MovementID 的多行表示该作业占用的不同 Cell。`Arr`、`Dep`、`Dw` 分别对应接车、发车、停留；时刻精确到秒，目前支持同一天内的作业。CellID 可填写站场中的 Cell 编号或名称。系统根据当前方案的名称、股道编号和拓扑匹配 Cell；无法唯一匹配时，在预览中手动选择对应 Cell。

默认新建独立计划，也可追加到当前计划。预览显示列车与作业数量、Cell 对应关系、复用及新建进路。新进路必须能在现有站场拓扑上形成有效路径。每个 Cell 的占用起止时刻分别保留；已有进路的占用参数不兼容时，另建进路以免影响其他计划。确认导入后自动切换至导入的计划。

追加时如存在重复列车编号，整批不导入；文件或站场/计划数据在预览后发生变化，需要重新预览。正式导入在一个事务中保存，新计划、进路和列车作业任一项失败都会回滚。

完整操作、转换限制、共享事件与锚的规则见[作业过程编排](../docs/operation-process.md)。

## 5. 求解与生成饱和计划

先启动独立 [CapacityAgent](../SwitchYard.WebApi/SwitchYard.CapacityAgent/README.md)，用有权限的账号连接当前 Web 服务。浏览器不能自行替代 Agent 运行求解。

在「模型求解」中：

1. 选择站场方案和作业计划，点击「生成输入」，检查服务端生成的 JSON；需要时可在输入框内编辑。
2. 选择在线、可用且有访问权限的 Agent，再选择模型。
3. 提交求解，查看进度、状态和结果；可下载结果 JSON。完成状态本身不代表存在可行解，还应核对结果的 `hasSolution` 和 `status`。
4. 在「求解预设」中保存 Agent、模型、左右时间容差、求解时限、线程数及目标，供后续重复使用。

当前模型 ID 是 `station-capacity-v1`，模型版本是 **2.0.0**。含作业过程约束的输入要求模型版本至少为 2.0.0。普通列车使用顺序作业及进路衔接约束，过程列车使用完整事件图；两者均受轨道电路占用互斥约束。

普通「模型求解」保留任务和结果 JSON 于服务进程内存，不自动改写计划，服务重启后不可依赖这些任务记录恢复。若要把优化结果用于后续分析和仿真，在「作业计划」顶部选择求解预设并点击「生成饱和计划」。成功获得并通过校验的可行解会另存为新的作业计划，页面自动选中新计划；源计划保持不变。生成的计划保留过程列车的约束副本、求解事件时刻和停留股道选择。

当前「饱和计划」是对已有列车及作业进行求解并保存，不会自动增加列车数量来搜索最大可开行列数。

## 6. 查看计划图与能力分析

这些功能均在「作业计划」的子页签中。选择原计划或生成后的饱和计划后查看：

- **作业计划图**：以轨道电路区段和时间为坐标显示作业占用，悬停查看作业信息。每次拖动仅平移当前占用块，左右端点仅调整该区段的占用起止时刻，其他区段和其他作业的时刻保持不变，拖动过程中不重新排列占用层级。区段调整随作业计划独立保存，不修改整项作业的起止时刻和进路公共占用参数；刷新、二维／三维回放和能力计算使用保存后的区段占用。调整精确到秒，端点不得交叉，并保留提前锁闭的负偏移和跨日占用。松开后自动保存，保存失败恢复原时刻，按 Esc 可取消拖动；由作业过程生成的作业继续遵循只读约束。
- **作业占用时间表**：按进路、固定与非固定作业汇总占用，支持总时间、空费系数及秒／分钟显示设置，也可配置区段子表。
- **作业瓶颈分析**：显示进路作业次数、瓶颈区段、利用率与通过能力估算。
- **能力分类汇总**：维护分类及其关联进路，点击「计算」汇总对应结果。

分析结果依赖当前计划、进路占用参数、总时间及空费系数。当前瓶颈能力按作业次数与瓶颈利用率推算，因此应在相同统计口径下比较。页面会保存分析快照和相关设置；数据变更后使用刷新或计算重新核对，不要把先前保存的分析当作新数据的结果。

计算参数、作业计划图、二维和三维仿真的轨道电路占用图共用功能区：自适应缩放、X 缩放、Y 缩放和刷新。自适应将时间轴和区段行分别调整至撑满可用窗口，并随窗口或数据变化继续调整；手动拖动任一缩放滑块退出自适应。刷新重新加载当前进路或计划数据。

### 中观作业计划图

「作业计划图」旁的「中观作业计划图」使用 `StationPlanView` 显示每列车的整条作业轨迹。时间轴沿用 GraphicalTimetable 的整点数字、10 分钟网格、半点虚线和整点加粗竖线。横线表示在区段停留，竖线表示区段或出入口之间的移动；同一列车的多项作业连接为一条折线，每段连续水平线上方标注车次号。

入口添加从左方指入的斜线，沿第一段竖线的方向接入；出口添加指向右方的斜线，沿最后一段竖线的方向指出。车次号平行标注在斜线上方。斜线为出入站标记，不改变作业时刻，图面预留边距以保证自适应缩放和时间边界处的标记完整显示。

点击「配置显示元素」选择纵轴上的轨道电路区段和出入口。出入口候选由当前车站方案的进路起终点生成，并优先使用绑定出入口的区间／专用线名称。选择按实例、车站方案、作业计划保存在数据库中，刷新后恢复，复制或修改计划编号时同步保留。可全选或清空各类元素；清空后不会自动恢复为全选。

配置中标注本计划列车实际使用的起终点。如果这些节点未选中，图面提示被隐藏的起终点，并可点击「补齐列车起终点」加入显示、保存配置。补齐保留已有区段和出入口选择，不增加中间作业的进路端点；相邻的出入口与信号节点按各自编号区分。接车起点仅存于旧计划的 `RouteIDList` 时，也可显示到停站区段的连接。

中观轨迹按进路的直接区段顺序连接，间接影响区段只参与占用分析，不作为列车经过的区段。相邻区段的锁闭占用重叠时，按后一区段开始占用的时刻交接，避免折线沿时间轴倒退。轨迹同时读取各占用块独立调整后的偏移。通过总时间范围、X／Y 缩放、自适应缩放和刷新调整图面；轴标签在滚动时保持同步。

用鼠标点选列车作业线的横线、竖线或出入口斜线，可将整条作业线选中并加粗；再次点击取消该列车的选中状态。可连续点选多列车，无需按住 Ctrl，车次图例同步显示选中状态并支持切换。缩放和刷新同一计划时保留仍存在的列车选择；切换实例、方案或作业计划时清空选择。

按 Esc 或点击图面上没有列车线条的地方，取消全部选择。鼠标悬停在列车作业线上时，整条线临时加粗；移开后，未选中的线恢复正常宽度，已选中的线继续加粗。悬停不会改变车次图例中的选中状态。

选中列车后，每段轨道电路停留横线的左右两端显示方形抓手。鼠标悬停抓手时保持普通指针，并弹出半透明信息框，显示车次号、作业轨道电路以及该抓手对应的开始或结束时刻；键盘聚焦抓手也可查看信息。左右拖动抓手可按秒调整对应边界时刻，连接的竖线随边界移动，拖动期间隐藏提示框；抓手获得焦点时，也可用左右方向键微调一秒。上下拖动横段可切换到显示的另一个轨道电路区段，不改变该段的起止时刻，其他列车不会跟随移动。

调整停留位置或时刻时，本图不进行合法性检测，不限制最小时长、作业先后次序或起止时刻的大小关系，流程生成列车也可以直接调整。换区段时，进路匹配仅辅助更新：按类型、区段位置及外侧起终点选择最接近的进路；多个候选时按匹配程度和进路 ID 确定一个，没有候选时保留原进路，并保存用户选择的区段。调整后的区段和原始起止时刻随作业保存，刷新后保留原样；计划合法性由其他模块负责检测。松开后自动保存到作业计划，相关作业在一次数据库事务内提交，旧版本或写入失败时全部恢复。拖动中按 Esc 取消本次调整并清空选择。

每次完成时刻或轨道电路调整，记录为一个 Action；一次横段调整涉及多项作业时仍只记一个动作。功能区提供「撤销（Ctrl+Z）」和「重做（Ctrl+Y）」，同时恢复或重放该动作涉及的时刻、区段和进路，并保存回作业计划。动作栈最多保留 20 个动作，超过时淘汰最早的动作；撤销后执行新调整会清除重做记录。失败或取消的调整不入栈，撤销／重做保存失败时保持当前计划和历史位置。历史保留在当前页面会话中，切换计划、重新打开页面或计划被其他操作修改时清空；刷新且数据未改变时保留。输入框内的 Ctrl+Z／Ctrl+Y 由输入框处理。

股道调整、撤销或重做导致进路变化时，保存成功后弹出消息，列出车次、作业名称和「原进路 → 新进路」（含进路名称与 ID）。消息显示 8 秒，可手动关闭。

## 7. 回放二维与三维仿真

「仿真」提供二维站场与列车位置、移动明细和占用图；「3D」提供三维站场和列车回放。两者均需选择站场方案及作业计划，可选择单列车或全列车，使用播放／暂停、复位、速度选择与时间滑块查看过程。

二维仿真的进路高亮与「进路设计」共用类型配色：接车为红色、发车为蓝色、机车出入段为绿色、调车为黄色。全站回放时，各条进路分别显示自身类型的颜色和方向箭头，占用图也使用对应颜色。

类型为 `Dw` 或 `Dwelling` 的进路按停留作业回放：列车在股道中央保持静止，直到停留结束。发车进路提前锁闭与停留时段重叠时，同一列车仍显示为停留，不会出现重复的移动列车。

3D 回放中，同一列车的各段进路统一采用其中较短的显示长度，接车、停留、发车时车长和车厢间距保持一致。列车沿轨道平滑驶入停车位置，停留结束后从原位起步；折返时车厢保持原有位置和朝向。默认以 10 倍速度回放，可按需调整速度。

通过侧栏和底部面板的分隔条为图形或明细分配空间。回放读取已有计划及站场路径，用于检查时序和空间表现，不会自行求解或修复冲突。若缺少列车、进路、轨道或时刻信息，先回到站场及作业计划页面补齐并刷新。

## 常见问题

| 现象 | 检查项 |
| --- | --- |
| 页面没有数据或操作按钮不可用 | 实例是否启用、有访问权限，方案和计划是否已选择 |
| 过程活动找不到候选资源 | 进路类型、节点连接、方案范围是否正确；停留 Link 是否有名称 |
| 生成计划失败 | 模板是否已保存且版本最新，资源是否仍存在，时间范围能否容纳全部约束 |
| Agent 不可选或任务不能提交 | Agent 是否在线、有空闲槽位、允许当前用户、支持所需模型版本 |
| 无可行解 | 时间容差、最小／最大时长、事件与次序约束、候选资源及占用偏移是否相互矛盾 |
| 求解完成但分析仍是旧计划 | 普通求解不会自动保存计划；使用生成饱和计划，或核对当前选中的计划 |
| 独立「结果分析」显示待开发 | 使用「作业计划」中的计划图、占用、瓶颈及分类汇总子页签 |
