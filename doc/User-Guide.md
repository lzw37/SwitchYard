## 1. 界面与操作约定

能力分析、课程等功能区的新增、编辑、保存、删除、刷新、运行等操作采用小圆形按钮。把鼠标停在按钮上可查看操作名称；键盘可用 `Tab` 切换焦点。灰色按钮表示当前条件不满足或操作暂不可用，应先选择实例、方案、数据或等待加载结束。表单中的字段名称、单位、状态及页签文字用于识别当前内容。

驼峰模块保留原有文字按钮、标题、工具栏和面板样式。纵断面两侧的工具和数据面板仍通过箭头展开或收起，具体操作见[驼峰使用说明](Hump.md)。

独立车站布置图控件保留自己的绘图工具栏和交互方式。其内部工具与应用外围的圆形按钮可能不同，具体见[能力分析使用说明](Capacity.md)。

### 调整侧栏和底栏

支持调整的面板之间有细分隔条。鼠标移到分隔条上时，指针变为左右或上下调整形状，按住拖动即可改变面板宽度或高度。调整范围受当前窗口及面板最小尺寸限制。

分隔条也支持键盘操作；先按 `Tab` 将焦点移到分隔条，或点击分隔条：

| 操作 | 效果 |
| --- | --- |
| `←` / `→` | 水平移动分隔条，调整侧栏宽度，每次约 10 px |
| `↑` / `↓` | 垂直移动分隔条，调整上下分区高度，每次约 10 px |
| `Shift` + 对应方向键 | 每次调整约 40 px |
| `Home` / `End` | 将被调整面板设为允许的最小/最大尺寸 |
| `Enter` 或双击分隔条 | 复位尺寸 |

右侧和底部面板随分隔条移动的增减方向与左侧、顶部面板相反。复位依据组件初始值或页面设置；这些尺寸不作为项目数据保存，重新进入页面后应按需要调整。

上述分隔条用于能力分析中的多个工作区和课程目录等，不用于驼峰平面图下方表格或纵断面侧栏。部分页面在窄窗口中会改为上下排列，对应分隔条也会改为上下拖动。驼峰主导航空间不足时会显示为下拉选择。

### 语言、保存与刷新

- 首页提供语言切换入口；驼峰页面使用中英文文字按钮，能力分析页面使用 `EN` / `中` 按钮切换中英文。语言选择保存在当前浏览器中。
- 语言切换作用于界面标签、按钮、提示和单位说明。用户输入的实例/方案/设备名称、课程资源原文及其他数据不会自动翻译；服务器返回的原始错误也可能保持其原有语言。
- 编辑表格或表单后，点击相应的“保存”，并确认成功提示。页面出现图形变化不一定代表数据已保存；个别图形操作有自动保存行为，以模块说明为准。
- “刷新”“加载”会重新读取数据。切换实例、方案或离开页面前先保存当前修改，避免把尚未提交的编辑当成服务器数据。

## 2. 登录与个人资料

登录入口为 `/login`。输入账号和密码后，点击登录按钮，或在密码框中按 `Enter`。业务数据的读取和修改需要有效登录状态；会话失效时按提示重新登录。

没有账号时，可从登录页的注册链接进入 `/createuser`。普通用户注册后可登录；自助注册选择管理员角色时，账号先处于未启用状态，需要现有管理员启用。创建账号还依赖服务器上的默认驼峰模板，初始化失败时请联系维护人员检查模板数据。

右上角用户菜单中的“个人信息”打开 `/userinfo`：

- 查看用户名、角色等账号信息，修改邮箱并保存。
- 修改密码时填写当前密码、新密码及确认密码。新密码为 6–30 个字符，不能与当前密码相同。
- 改密成功后程序退出当前会话，使用新密码重新登录。
- 用户菜单和个人信息页均提供退出登录入口。

管理员创建、批量导入或由管理员重置密码的账号会被标记为“必须修改密码”。登录后会先进入个人信息页，完成改密前不能继续访问其他页面；这与普通用户主动注册后的流程有所不同。

## 3. 管理员操作

管理员可从用户菜单打开“用户管理”(`/usermanagement`)。普通用户看不到该管理入口，也不能通过直接输入地址获得管理权限。

用户管理提供以下操作：

- 搜索、分页查看账号；新建账号，设置角色、邮箱和启用状态。
- 编辑账号资料、启用或停用账号、重置密码、删除账号。界面禁止删除当前登录账号。
- 下载 Excel 导入模板，按模板填写后批量导入；查看每一行的成功或失败结果，修正失败行后再处理。

驼峰页用户菜单中的“实例管理页面”(`/hump/instancemanagement`)是管理员入口，可管理实例及所属用户。驼峰页左上角的“计算实例管理”是工作页中的实例管理窗口，两者入口和管理范围不同。

## 4. 使用课程

从首页进入课程页面 `/courses`。课程目录按“篇 → 章 → 节”组织。

1. 点击篇或章可展开目录，并在右侧查看相应的重点和难点；没有资料时显示空状态。
2. 点击具体小节，在右侧查看该节视频、PDF 课件和填空练习。
3. 同一小节有多个视频时，用视频选项切换，播放、音量和进度使用播放器控制条。
4. 同一小节有多个 PDF 时，先选择文件，再用前后翻页按钮或邻近页缩略图浏览；课件需加载并渲染后才显示。
5. 填写练习答案后，点击“评分并查看答案”按钮查看正确数、每题判定、相似度和参考答案。评分在当前页面完成，当前实现不向服务器提交成绩，也不提供刷新页面后的答题记录恢复。

课程目录与内容之间的分隔条可拖动；窄窗口下目录位于内容上方，可调整目录高度。

课程页面读取服务器已配置的教学资源。当前页面没有教学资源上传、课件编辑或教师成绩管理后台。视频能否播放还取决于文件编码和浏览器支持；文件扩展名出现在服务器资源列表中不代表浏览器一定能解码。

## 5. 常见问题

| 现象 | 处理方式 |
| --- | --- |
| 找不到按钮含义 | 悬停查看提示；结合旁边的字段、所选行和当前页签判断操作范围。 |
| 表格或侧栏太窄 | 有分隔条的面板可拖动调整，或聚焦后用方向键调整；驼峰纵断面可用箭头收起当前不使用的侧面板。 |
| 反复进入个人信息页 | 检查是否要求先修改密码；完成后用新密码重新登录。 |
| 无权限、账号停用或看不到实例 | 确认当前账号、角色、启用状态及实例所属用户，联系管理员处理。 |
| 保存或计算失败 | 保留错误提示，检查选择项和必填数据；驼峰缺失引用见[驼峰指南](Hump.md)。 |
| 课程目录为空、视频或课件缺失 | 联系维护人员确认服务器的 `Course:VideoDir`、`Course:DocDir` 和实际资源目录；配置方法见[部署说明](Deploy-Instruction.md)。 |
| 英文界面仍显示中文名称 | 用户数据和教材原文按原文显示；如为按钮或提示未翻译，可记录页面位置和文字供维护人员核对。 |
