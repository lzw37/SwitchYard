# 牵引计算前后端接入

运行曲线由后端 `SwitchYard.SpeedProfile` 计算。前端保留站场拓扑展开、参数编辑、图形渲染及服务端采样点的光标插值；不再生成牵引/制动速度曲线或绝缘、轨道电路占用结果，服务不可用时不回退到浏览器求解。

## 节点实际坐标

单条与批量计算展开进路时，优先使用节点的 `actualX` 作为横坐标；未填写或清空时继续使用图面横坐标，Y 坐标保持原有值。零、负数和小数均有效。实际坐标沿用当前距离标尺与单位换算；已明确填写的线路实测长度 `lengthM` 仍优先于坐标推导长度。曲线按修正后的相邻线路及原半径重新计算切线和弧长，设备、绝缘及轨道电路里程同步更新，原布置图数据不被修改。若原半径无法适配修正后的线路，提示曲线几何无效。

在布置图中保存坐标后，重新进入牵引计算或点击刷新可读取最新数值；点击“计算”或“批量计算”生成新结果，已有计算快照不会自动重算。

## 接口

`GET/PUT /api/SpeedProfile/workspace` 按实例、站场方案、计算方案和进路记录读写关系化牵引参数；`POST /api/SpeedProfile/workspace/calculate` 校验已保存版本，计算并原子保存输入及结果；`GET /api/SpeedProfile/workspace/calculation` 读取最近结果。沿用应用 JWT 与实例 Owner/Admin 权限。原 `/api/SpeedProfile/calculate` 保留为兼容的无状态计算接口，牵引页面已不再使用。完整契约、单位、错误格式及示例见 [后端 API 文档](../../../SwitchYard.WebApi/SwitchYard.SpeedProfile/API.md)。

- 前端输入采用 m、s、t、kN、km/h；Davis 系数使用 `R(kN)=A+B*v(km/h)+C*v(km/h)^2`。全部 SI 换算在后端完成，尤其 `B*3600`、`C*12960`。
- 牵引表速度从 0 严格递增、力非负非递增；制动、阻力也为速度—力表，允许力随速度增减。三表均分段线性插值，表尾以末点力延伸。恒定制动力和 Davis 系数仅用于显式生成表格，每 10 km/h 取点并包括最高速度；有离散表时不直接使用生成公式计算。
- 每段可编辑坡度、限速及附加阻力 kN；可增加沿进路里程的停车点和停时。
- 允许速度按阶梯锚点编辑：点击限速线进入编辑模式，双击限速线插入锚点，拖动调整位置和速度，右键锚点打开删除菜单（也支持 Delete）。Esc 或点击图面其他位置退出并隐藏抓手；视图不显示编辑按钮或数值输入栏。0 m 首点保留；每点控制其后到下一点前或终点的限速。最多 1000 点，按当前方案和进路保存为关系行；分割限速时保留原坡度和阻力边界。上图不绘制绝缘，信号只显示自身名称，道岔编号加“岔”。
- 起终点速度作为期望上限传入后端，实际速度可因限速、制动、牵引及停车条件降低；界面区分期望输入与实际计算速度，并提示速度降低。接车末速为 0，发车初速为 0；步长和点数预算均传入后端，预算包含停车产生的重复里程点。占用图、车尾出清、释放和参数回填使用实际运行曲线时刻，保存的期望输入不被结果改写。
- 界面维护与摘要均使用回转质量系数 `γ`（0～2），有效惯性质量为 `m × (1 + γ)`。保存及 API 中的 `rotatingMassFactor` 仍表示倍率 `1 + γ`（1～3），读入时减 1、编辑时加 1；已有 1.08、1.1 分别显示为 0.08、0.1，历史数据与结果无需迁移或重新计算。
- 车长用于车尾出清及解除限速。坡度/附加阻力按车头所在段的单质点模型处理，非零坡度结果显示该假设。
- `durationS` 含停车时间；`runningTimeS` 是纯运行时间；`totalTimeS` 还包括办理进路及反应时间。停站处的重复里程点表示到达和停时结束。
- 工作区首行依次显示制动距离、原进路长度（不含入口前制动段）、实际入口/出口速度、全程时间（含接近）和占用时间（最小间隔）。全程时间为已保存运行曲线首末采样时刻之差，包含接近和停车；占用时间取图中可确定总占用时间的轨道电路最大值，悬停显示对应区段及精确秒数，时刻不完整的区段不编造总时长。两项时间与图内标注统一采用 `mm:ss`；参数编辑后仍显示上次计算快照。

## 调车作业

作业类型增加“调车”（`shunting`）。新选中的调车进路默认使用此类型，切换为调车时起点、终点期望速度均设为 0，两项输入保持可编辑；已保存调车记录恢复用户自己的速度，不重置为默认值。调车仅使用原进路长度、线路、设备、绝缘和轨道电路，不追加制动距离或一离去区段；对应距离和两项扩展最高速度输入隐藏，即使切换前留有其他作业的扩展参数，调车计算和结果读取也忽略这些设置。曲线、占用图、参数回填、导出和方案复制支持调车；最终停车且车尾未出清的区段，物理释放时刻仍未知，但占用在终点首次停车时刻结束，回填按该时刻相对各进路结束参考换算。若用户设置非零末速，仍按实际末速计算车尾出清时间，不扩展车头运行曲线的里程。

## 接车、通过制动预留段

接车、通过参数提供可选的“制动距离 (m)”输入。留空时，后端复用现有反向制动包络，从制动段有效最高速度自动计算至 0 的制动距离；已填写时直接使用输入的米数，不按步长取整，再将有效距离追加到进路入口前。清空输入恢复自动计算，显式输入 0 表示不追加。参数及输入快照分别保存可空数值，旧记录默认留空；结果摘要、坐标平移、接近及占用时间使用本次计算实际采用的距离。入口外沿用首段坡度及附加阻力；运行设置中的起终点速度为期望上限，实际速度由完整曲线求解。界面分别显示制动距离和原进路长度；原进路设备、绝缘、区段及停车点同步平移。前端只平移显示坐标，不计算制动距离。自动追加段不可编辑限速，原进路限速编辑坐标在提交时换回原坐标。旧快照保留，点击“计算”后应用新规则，重复计算不累加预留距离。工具栏“显示站外内容”默认开启；关闭后将入口前制动段从上下两图隐藏，站内进路铺满横轴，保留原位置与时间坐标。开关只控制显示，联动光标与限速编辑使用可见范围，不触发计算或修改已保存参数、结果。

接车的下方时刻图以黄色矩形显示每个轨道电路的接近时间：所有区段统一以车头刚进入整条接车进路的制动距离范围（已保存运行曲线的起点）的时刻为开始，各自以车头进入该区段的时刻为结束。所有黄色矩形的上边缘对齐，横向覆盖对应区段，悬停显示起止时刻及持续秒数。其上方依次为绿色进路办理矩形（0 至办理结束）和灰色反应时间矩形（办理结束至接近开始），宽度与对应轨道电路一致；零时长不绘制矩形。两段采用计算快照中的信号参数，未重新计算的编辑不会改变显示。区段占用矩形在车尾离开该区段时结束，之后至区段释放时刻单独绘制红色“释放时间”矩形；采用保存的退出与释放时刻，零释放延时或时刻未知时不绘制红色矩形，终点停车后仍被列车覆盖的区段以首次停车时刻结束占用，不加终点停时或释放延迟；其他结束时刻未知的区段以斜纹表示。显示只对已保存结果做时间插值，不触发后端计算；缺少制动距离、入口边界或完整运行范围时不编造接近时间。

发车占用图也显示办理、反应和接近三个阶段。接近时间统一从车头进入沿进路里程排序的首个轨道电路时开始，至车头进入各自区段时结束；首个区段的接近时间为 0，仍绘制其办理和反应阶段。办理、反应采用计算快照的参数，以办理开始（0 秒）为基准，不随首区段位置或显示范围平移。各区段的总占用时间从办理开始延续至该区段车尾出清并释放结束，悬停可查看总时长。首区段进入时刻未知时不以更后面的区段替代；出清或释放时刻未知时不显示虚构的总时长。

通过占用图沿用接车的时刻分段规则，显示办理、反应、接近、区段占用和释放时间。各区段统一从车头进入入口前制动预留范围（已保存运行曲线起点）的时刻开始累计接近时间，至车头进入自身区段时结束；办理从 0 秒开始，总占用至各区段出清释放结束。显示范围裁剪不改变共同时间起点，参数来自计算快照。旧的无预留段通过快照按原范围显示，重新点击“计算”后生成预留段；缺失运行起点、区段进入或释放时刻时，不编造相应阶段或总时长。

坐标图内在各区段释放边缘附近直接标注总占用时间，采用 `mm:ss` 格式，按秒四舍五入；引线对应区段，悬停可查看名称、起止时刻和精确秒数。窄区段的标签自动错行，必要时增大图形高度并在面板内滚动；总时长无法确定时显示 `--:--`，不以 0 或当前图形窗口结束时刻代替。

“制动段最高速度 (km/h)”和“一离去最高速度 (km/h)”为独立可选参数：留空或清空采用列车最高速度，填写时采用设置值并受车辆最高速度约束。前者同时用于自动制动距离起始速度和入口前区段限速，手动制动距离不被速度设置改写；后者用于发车、通过末端一离去限速。两段限速在曲线中独立显示，站内限速锚点编辑不会改写这两项参数。参数、结果输入快照和方案复制均保留空值或具体数值。

## 发车、通过一离去区段

发车和通过参数均提供“一离去长度 (m)”输入（0～100000 m，0 表示暂不追加）。输入正长度并点击“计算”后，后端在原发车进路或完整通过进路末端追加一个“一离去”轨道电路，沿用末段坡度及附加阻力，一离去限速单独设置，原进路设备和停车点坐标不变。期望终点速度约束追加区段末端；全程时间计至车头到达该末端，“一离去”的出清、释放和总占用时间参与图形、明细及最小间隔汇总。末端停车导致无法确定释放时刻时仍保留未知。通过进路同时保留入口前制动预留段，两端扩展分别计长，制动距离摘要不包含一离去长度。长度随进路记录落库、复制，旧数据默认为 0；重复计算不累加区段。站内原区段回填使用延长曲线的出清释放时刻，进路起止事件仍采用原进路边界；“一离去”仅为计算追加区段，没有站场 CellID，不向原站场参数集写入虚构区段。

## 占用参数回填

接车、通过计算以车头首次进入进路起点、首次到达进路末端作为进路起止事件，发车保留原有的进路起点出发基准。四类作业的所有途经区段均从进路办理开始（0 秒）预先占用，开始偏移为 0 减进路开始时刻；结束偏移为区段出清释放时刻减进路结束时刻，回填窗口包含办理、反应、进入各区段前的接近时间以及区段占用和释放时间。接续进路分别按各自起止事件换算，同样回溯到本次计算的办理起点。各类作业最终停车时仍被列车覆盖的区段（含末端截断的区段）统一在终点首次停车时刻结束占用，结束偏移为该时刻减对应进路结束参考；二者重合时为 0，仍被占用的前一进路或一离去前的站内进路可为正值。占用图、总占用时间、摘要、明细及单条/批量回填共用同一规则，不包含终点停时和额外释放延迟，也不改写快照的物理出清、释放事件。已有结果可直接按此规则显示和带入。其他缺失记录、异常时序及无法确认占用状态的区段保留原值。参数表采用整秒，开始向下、已释放结束向上取整。占用明细预览和保存采用同一换算；只有用户点击“更新计算参数”才写入选定计算参数集，同时按进路结束减开始保存作业时间（秒，保留小数）。后端在同一事务中保存区段偏移与作业时间，响应同时确认两者。计算参数页用作业时间展开两个不同的时间基准，绘制前段、虚线和解锁段。

## 项目统一列车参数

同一项目（当前 InstanceID）只维护一份列车参数库，各车站、计算方案和进路共用。“维护项目列车参数”在一处新增、修改、删除预设及三个特性表，最多 1000 个；各进路独立保存所选列车 ID，其他运行、信号、停车和线路设置仍独立。批量计算及统一设置也只引用此库；在任一批量入口保存项目列车参数后，同步已载入草稿中的定义并保留其列车选择与其他输入。

修改列车物理参数后，使用该列车的进路结果变为待计算，历史快照保留且不自动重算；仅重命名不使结果过期。删除正在使用的预设时，相关进路改选项目默认列车。旧站场/进路库自动合并：相同定义去重，同名但参数不同的预设保留为带后缀的版本，并保留原进路选择。项目库与工作区分别校验版本，过期草稿必须重载，不能把旧的进路参数副本写回共享库。复制计算方案只复制列车选择和路线参数，读取同一项目库。不同项目互不影响。

## 多套计算方案

层级为“车站 → 计算方案 → 进路记录 → 参数与结果”。同一方案可容纳多条进路，主进路与接续进路的组合分别保存，切换时恢复各自的参数、停车设置及曲线。“方案进路结果”可查看、切换、删除单条记录，也提供“批量计算”页签。工具栏“计算方案”选择同站场内的独立方案；“管理”支持新建、复制（含已有结果）、重命名、删除。至少保留一套，最多 100 套，名称不重复。方案列表和当前选择落库；切换前提交原方案待保存参数，失败时停留在原方案。所有工作区与计算请求均携带 `calculationSetID` 和 `routeCaseID`，单次计算只覆盖对应进路记录。整方案复制包含其中全部进路、参数和已有结果。新建方案没有结果，点击“计算”或“批量计算”才生成；切换和管理操作不计算。旧版单套关系数据原子迁入默认方案，浏览器旧数据仅可迁入默认方案。

批量列表包含全部站场进路（包括未建立计算记录的进路）及当前方案已保存的接续组合，支持搜索、状态筛选和勾选；表头全选只作用于当前筛选结果，切换筛选保留已勾选项。点击一行，在右侧编辑列车、作业与运行参数、信号时间、距离标尺、分段线路和停车点。已有记录使用自己的参数；新记录继承当前工作区的列车与通用设置，按进路类型初始化作业和期望速度，并清空其他进路的停车点、速度锚点。调车仍只计算原进路。统一设置按勾选的参数组应用至所选进路；默认保留各进路作业类型，停车点、速度锚点和分段覆盖始终分别维护。统一列车设置仅选择项目库中的列车，不复制或新增进路私有预设。

弹窗编辑为本次批量草稿，点击“批量计算”才保存并计算选中的进路。计算按队列逐条提交并显示进度、成功和失败数量；单条失败继续后续项，可修改后重试失败项。停止后续计算会等待当前进路完成保存，已完成结果保留。每条保存独立校验版本，冲突需重载参数，失败保留上一份结果；参数若已保存而计算失败，该进路为待计算。批量不切换工作区当前进路，完成后刷新结果列表及受影响的当前曲线。占用偏移仍通过“更新计算参数”明确写入参数集。

“已有结果”支持勾选多条有效结果，选择目标计算参数集后，点击“带入计算参数”，一次写入进路作业时间与公共轨道电路占用偏移。未计算、待计算或已删除的进路不能勾选。写入前重新读取每条工作区及结果，核对保存版本、结果归属和当前站场线路；过期、变更或读取失败时不写入目标。通过结果同时处理其主进路和接续进路；多个所选结果对同一进路产生完全相同的参数时合并一次，时间不同时提示只选择一个对应组合。读取并校验全部目标原值后逐条保存，保留时刻未知及其他已配置区段，不创建计算专用“一离去”参数行。保存响应确认后才计入成功，部分失败显示已完成进路及错误，能力计算参数页刷新对应参数集与进路。

所有占用时刻未知时，通过 `operationTimeOnly=true` 单独保存已知作业时间，保留原占用行，且不制造空值或零值行。该分支与原完整保存的隔离数据库回归可运行 `dotnet run --project SwitchYard.WebApi/SwitchYard.Service.RegressionTests`（仓库根目录）。

## 交互与参数迁移

计算参数页的“牵引计算”弹窗读取当前实例、车站和进路的数据库计算快照，优先读取当前进路的独立结果；独立记录不存在或没有计算快照时，再读取包含当前进路（主进路或接续进路）的接续计算结果。多个接续组合优先读取有效结果，再按保存时间从新到旧查找，均没有快照时显示“未计算”。允许切换牵引计算方案，不提供进路记录切换；采用接续结果时以只读文字标明组合进路。弹窗与牵引计算页共用运行摘要、速度–位置图和位置–时间占用图，采用紧凑布局降低图表最小高度并完整保留坐标轴，制动预留段、一离去区段及信号时间均采用结果保存时的输入；只读查看不切换工作区的已选方案或进路，也不触发计算或回填。没有结果时仅显示“未计算”，旧结果标明“待计算”，读取失败时提供重试；切换范围或关闭后忽略迟到响应。

页面载入、刷新和重新进入模块只读取数据库参数和最近计算快照；没有结果时显示可编辑限速及设备位置，占用图保留空态。编辑参数仍自动保存，但不触发计算。“计算”和“批量计算”按钮是显式计算入口：先保存对应参数，再请求后端计算并落库，成功后替换旧快照。输入变化取消在途请求并保留旧结果，标记“待计算”；失败也保留旧曲线。切换实例、方案时清理上一范围结果，版本检查防止迟到响应覆盖新范围。运行速度、占用图及导出使用快照自带的进路、车长及输入；允许速度线显示当前编辑值，更新占用时间仅在快照与当前输入一致时可用。

牵引业务数据不再写 localStorage。数据库无记录时只读旧 v1/v2 参数及列车预设，成功落库后移除旧记录；后续直接读数据库。完整参数和最近计算结果分别写入关系表，每套方案中每个节点、停车点、分段、采样点及占用时刻均为独立行，禁止 JSON/blob 文档字段。详见[关系存储设计](../../../docs/zh-CN/traction-database.md)。切换到已有进路记录时恢复其停车点；首次打开新的进路组合时清空继承的停车点，避免误用里程。

```powershell
dotnet run --project SwitchYard.WebApi/SwitchYard.SpeedProfile.RegressionTests/SwitchYard.SpeedProfile.RegressionTests.csproj -c Release
```

dotnet run --project SwitchYard.WebApi/SwitchYard.SpeedProfile.ApiTests/SwitchYard.SpeedProfile.ApiTests.csproj -c Release
