# SwitchYard

[English](README.en.md) · **[文档中心](docs/README.md)**

SwitchYard 是面向铁路站场与枢纽教学、方案编制和计算分析的工具集，提供驼峰设计与溜放仿真、车站通过能力分析、作业过程编排、布置图分析和课程资源。
