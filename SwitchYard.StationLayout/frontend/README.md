# @switchyard/station-layout

用于嵌入 Vue 应用的站场布局组件。宿主提供 Gateway、认证、业务范围和容器尺寸；包不内置业务数据库或服务地址。

A station layout component for Vue applications. The host provides the Gateway, authentication, business scope, and container dimensions; the package does not embed a business database or API address.

完整接入、JSON 格式、保存并发和验证说明统一维护在仓库 `docs/`。此 README 随 npm 包分发，使用在线仓库文档地址。
