# SwitchYard

[中文](README.md) · **[Documentation center](docs/README.md)**

SwitchYard supports railway station and terminal teaching, planning, and computational analysis. It provides hump design and rolling simulation, station capacity analysis, operation process modeling, facility layout analysis, and course resources.
