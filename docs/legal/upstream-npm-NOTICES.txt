SwitchYard supplementary upstream npm license notices
Reviewed: 2026-10-11

These exact upstream license files supplement package archives that omitted their
license text. Each source is pinned to the gitHead in the official npm registry
record for the package version shown below. The SHA-256 is for the original
source file bytes, which are reproduced below without alteration.

This supplement does not change the findings in npm-inventory.json: those findings
describe the actual installed package contents. It is not a complete binary SBOM.
In particular, a repository's MIT license is not a substitute for separate notices
for third-party code compiled into native esbuild, Rollup or canvas binaries;
canvas's Skia/ICU components require the corresponding binary distribution review.
