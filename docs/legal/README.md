# 许可资料目录 / Licensing material

[文档中心 / Documentation center](../README.md) · [中文许可维护说明](../zh-CN/11-licensing.md) · [English licensing guide](../en/11-licensing.md)

项目许可正文为根目录 [LICENSE](../../LICENSE)。本目录保存第三方声明与版本证据，不能把清单生成成功当成发行包已完成许可核验。

The project license is the root [LICENSE](../../LICENSE). This directory retains third party notices and version evidence; successfully generating an inventory does not establish that distribution review is complete.

| 文件 / File | 维护方式 / Maintenance |
| --- | --- |
| [source-assets-NOTICES.txt](source-assets-NOTICES.txt) | 源码素材来源，人工核对 / Manually reviewed source assets |
| [npm-inventory.json](npm-inventory.json)、[npm-NOTICES.txt](npm-NOTICES.txt) | [npm 采集脚本](../../scripts/collect-npm-licenses.mjs)生成 / Generated by the npm collector |
| [nuget-inventory.json](nuget-inventory.json)、[nuget-NOTICES.txt](nuget-NOTICES.txt) | [NuGet 采集脚本](../../scripts/collect-nuget-licenses.py)生成 / Generated by the NuGet collector |
| [upstream-npm-NOTICES.txt](upstream-npm-NOTICES.txt)、[upstream-nuget-NOTICES.txt](upstream-nuget-NOTICES.txt) | 固定上游版本补充，人工核对 / Manually verified upstream supplements |
| [licenses/](licenses/) | 与素材声明关联的许可原文 / Original license texts referenced by asset notices |

再分发时一并保留适用声明和被引用的全文，维持此目录内相对路径。查看两个语言版本的第 11 章了解发布步骤、检查命令与尚未完成的核验项目。

Retain applicable notices and referenced texts together when redistributing, preserving relative paths within this directory. Chapter 11 in either language explains packaging, check commands, and outstanding review items.
