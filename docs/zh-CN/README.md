# SwitchYard 中文说明文档

[English](../en/README.md) · [双语总目录](../README.md) · [项目首页](../../README.md)

这套说明面向使用程序的教师、学生、方案编制人员，以及负责部署和二次开发的维护者。内容对应 2026-10-11 的仓库实现，既说明如何完成工作，也说明计算假设、保存范围与当前限制。英文版按相同编号提供完整对应章节。

Docker 部署章核对至 2026-10-15；各章的适用范围以章首核对日期为准。

## 归档与维护

[文档中心](../README.md)集中管理现行手册、历史资料和维护规则。现行操作、计算、部署及开发说明只在本目录与英文目录维护；根目录和模块 README 提供简短介绍与导航。

原有 17 份 Markdown 文档和 1 份 H5 素材已集中到 `docs/archive/`。原文段落保留，Markdown 增加历史标注并调整链接，H5 原样保留。请通过[归档索引与迁移对照](../archive/README.md)查找原项目说明、专题指南、模块开发说明、审阅记录和宣传素材，以及它们对应的现行章节。

旧资料中的模型版本、测试结论和代码行号有其历史背景；部分测试资源与演示 GIF 在整理前就未随仓库提供，详见[缺失资源记录](../archive/README.md#missing-resources)。更新文档请遵循[文档维护约定](../MAINTENANCE.md)。

## 阅读约定

命令会标明执行目录；示例中的 `<...>` 为需要替换的占位值。实例、方案、计划、模板和列车 ID 属于不同范围，不能相互代用。文档中的单位与公式属于对应模块的实际口径，不因界面语言切换而改变。

文档中的“已实现”表示当前代码提供相应功能，并不意味着任意数据、任意部署均已通过验证。旧测试记录不等同于本次部署结果。升级程序后应同步更新中英文相同编号章节，并保留仍有价值的历史资料及其时间背景。
