# 驼峰设计、溜放检算与仿真

[文档目录](README.md) · [English](../en/03-hump.md)

本文覆盖 `/hump` 的当前功能，核对日期为 2026-10-11。
适合先了解对象关系，再按完整流程建立可计算实例；账号及公共界面见[使用指南](02-user-guide.md)。
计算方法一节描述代码实际实现，不能将图形或结果解释为程序已完成所有工程规范校核。

## 1. 实例与数据依赖

进入驼峰页后，先在左上角选择已启用的实例。
普通用户访问自己的实例，管理员可管理更广范围的实例及所属用户。
停用实例不再出现在工作页实例选择框中。
切换实例时，平面、车辆、工况、纵断面、计算条件和检算方案一起切换。

| 对象 | 内容 | 入口 |
| --- | --- | --- |
| 驼峰实例 | 一套设计数据的容器 | 左上角“计算实例管理” |
| 溜放线 | 平面控制点、区段、道岔、减速器 | 平面展开图中的溜放线管理 |
| 车辆参数 | 长度、质量、迎风面积、轴数、计算标签 | 计算参数上半部 |
| 运行工况 | 速度、风、密度和温度 | 计算参数下半部，界面标题“计算条件” |
| 纵断面方案 | 位置、高程及其坡段 | 纵断面设计中的方案管理 |
| 计算条件 | 车型、工况、溜放线、纵断面、减速器状态的组合 | 纵断面设计中的计算条件管理 |
| 检算方案 | 纵断面、溜放线、推峰速度及按顺序排列的钩车 | 车辆溜放检算中的方案管理 |

“运行工况”和“计算条件”不是同一条数据。
先建立车辆与工况，再把它们绑定到纵断面的计算条件，检算页才能选择相应钩车。
一条钩车记录引用一项计算条件，并用顺序号确定前后关系。

工作页“计算实例管理”支持新建、复制、改名、启停和删除。
复制输入新名称，编号由系统生成；复制实例适合保留原方案开展比较。
新建空实例不会自动补齐后续全部设计对象。
用户菜单中的“实例管理页面”是 `/hump/instancemanagement` 管理员页面，与工作页弹窗入口不同。

## 2. 完整工作流与结果

| 阶段 | 先准备 | 主要输出 |
| --- | --- | --- |
| 平面展开图 | 溜放线、控制点和设备 | 可保存的平面与设备引用 |
| 计算参数 | 车辆、工况 | 可复用基础参数 |
| 纵断面设计 | 控制点、完整计算条件 | 能高曲线、速度、阻力明细 |
| 车辆溜放检算 | 纵断面、溜放线、钩车顺序 | 速度—距离、时间—距离及相邻间隔 |
| 2D / 3D 仿真 | 有效检算方案及轨迹 | 按时间播放的车辆示意 |

开始比较前先复制实例或纵断面方案，并使用能区分试验条件的名称。
每次只改变一个待比较因素，更容易解释曲线差异。
名称不是关联键；重命名对象不等于建立或修复引用。
完成一阶段后先保存，再进入下一阶段。

## 3. 平面展开图

1. 打开“平面展开图”，选择溜放线。
2. 若列表为空，在溜放线管理中新建并保存；也可复制、重命名或删除已有线。
3. 在下方控制点表新增或插入控制点，填写编号与 `X` 坐标。
4. 控制点改变后点击区段表旁“更新”，核对各区段的起点、终点、长度、曲率、方向及位置参数。
5. 在道岔页签添加道岔，绑定当前线路的控制点并填写设备参数。
6. 在减速器页签添加减速器，绑定当前线路区段。
7. 对照上方图形和下方表格，点击顶部“保存”。
8. 必要时重新加载核对；“加载”会读取服务器数据，应先保留需要的修改。

图中选择与表格行联动，可用来定位设备和控制点。
平面控制点顺序、区段端点和设备绑定应共同组成连续的溜放路径。
计算中区段的位置参数区分溜放部分 `0` 与调车场 `1`。
平面中的设备位置参与阻力和时间检算，不只是装饰图元。
修改平面后应重新计算已有条件和检算方案；不能继续沿用旧图中结果。

## 4. 车辆和工况输入

进入“计算参数”，先逐行建立车型和运行工况并保存。
表格编辑状态与已保存状态不同；离开页面前检查每一行。

| 车辆字段 | 单位或含义 |
| --- | --- |
| 车型名称 | 计算条件引用的名称 |
| 长度 | m；影响检算时的车辆释放时刻 |
| 自重 / 载重 | t；总质量 `Q = 自重 + 载重` |
| 迎风面积 | m² |
| 轴数 | 参与等效重力加速度修正 |
| 车辆标签 | `难行车`、`中行车`、`易行车`；分别映射为 `1`、`0`、`-1` |
| 重力参数 `g` | m/s²；模型默认值为 `9.8` |

车辆标签是程序识别的业务值，不应直接改成任意英文字符串。
总质量必须有意义，避免总质量为零导致除法无效。

| 工况字段 | 单位或含义 |
| --- | --- |
| 峰顶速度 | m/s；用于该工况的初始动能 |
| 溜放部分 / 调车场速度 | m/s；各区域阻力公式的代表速度输入 |
| 风速 | m/s |
| 风向标志 | `1` 为逆风，`0` 在界面显示为顺风 |
| 气流密度 | 模型注明 kg·s²/m⁴；不要直接当作 kg/m³ 的数值 |
| 温度 | °C |

若原资料速度为 km/h，除以 `3.6` 后再输入 m/s。
工况的代表速度不是求解后每个位置的瞬时速度，后者显示在结果表中。
当前风阻实现对风向 `0` 的处理见第 7 节；不要据界面名称假定实现了任意风向动力学。

## 5. 纵断面设计与计算条件

1. 进入“纵断面设计”，新建或复制方案并选中。
2. 在图底部加点线上移动鼠标，点击跟随位置的“+”加点；空方案会初始化控制点。
3. 上下拖动控制点调整高程；按住 `Alt` 开始拖动可改变水平位置。
4. 使用右侧“数据”面板精确填写控制点位置与高程；区段表显示长度、坡度及高差。
5. 右键控制点打开菜单删除节点。方案管理中的删除操作在只剩一个方案时禁用。
6. 打开计算条件管理，新增条件并绑定已保存的车型、运行工况、溜放线及当前纵断面。
7. 编辑“减速器状态”，选择实际减速器，设置启用、总制动能高及输出比例并保存。
8. 选中条件，确认顶部车型、溜放线、工况摘要与预期一致。
9. 手工表格编辑后点击保存，再执行计算。

减速器输出比例使用 `0–1`，例如 `0.5` 表示所设总制动能高的 50%，不是填 `50`。
停用减速器不参与该计算条件的制动能高累计。
同一物理减速器可在不同计算条件中采用不同状态，便于比较调速组合。

图上增点、删点和拖动完成后会触发保存，条件齐备时还会重新计算。
表格中的未提交数字不等于图形自动保存已完成；以保存及计算提示为准。
失败时检查引用，再用顶部按钮保存、计算，不要只看图形是否移动。

左右箭头用于展开或收起工具和数据面板。
显示开关控制初始动能、阻力能高、动能高、制动能高、设备和标签。
横纵缩放只影响观察比例，不改工程数据。
右侧能高表可核对位置、能高与瞬时速度，点击阻力区域可查看当前位置的分项明细。

## 6. 如何阅读能高结果

当前位置高程、初始动能高、累计阻力、累计制动共同决定动能高。
其中“能高”的单位为 m，是按单位重量表达能量，并非全部曲线都代表实体高程。
阻力明细包含基本阻力、风阻、道岔和曲线四项，以及对应输入参数。
检查明细时应同时核对当前横坐标、车型、工况和所用溜放线。
曲线突然截断或速度为零时，先检查能量是否耗尽及平面、纵断面的公共范围。
截图适合保留比较过程；当前工作流不提供完整工程审查报告的自动签发。

## 7. 当前计算模型

下列公式直接整理自计算源码，便于复核程序行为，不代表公式适用性已经独立验证。
令 `Q` 为总质量、`n` 为轴数、`z(x)` 为纵断面高程、`v₀` 为工况峰顶速度：

```text
g' = g / (1 + 0.42 n / Q)
h₀ = v₀² / (2 g')
hK(x) = max(0, h₀ + z(0) - z(x) - hR(x) - hB(x))
v(x) = sqrt(2 g' hK(x))
```

结果中高程、阻力能高、制动能高和动能高取到 3 位小数，速度取到 2 位小数。
纵断面以 `x=0` 的高程作为上述初始势能基准，因此建模时应统一里程起点。
负动能被截为零；该处理不会输出“负速度”。

基本阻力采用以下实现，`t` 为温度、`k=0/1` 对应溜放部分/调车场、`c` 为车辆标签参数：

```text
σ = 0.602 - (0.0012 + 0.00002 Q)t - 0.003 Q + 0.00002 t²
r = 2.439 + (0.00008 Q - 0.01743)t - 0.015 Q + 0.00017 t²
    + 0.1 v + 1.65 c σ + (1-k)0.39                     [N/kN]
```

风阻代码固定 `β=0`、阻力系数比为 `1`，当前实现等效为 `ρ F (v + I v风)² / (2Q)`。
`I=1` 增加逆风相对速度；`I=0` 会把风速项消去，未实现以负风速模拟的完整顺风关系。
这属于当前实现限制，比较顺风方案时需明确记录。

曲线阻力功为总转角（含道岔曲线转角）乘 `8 N·m/kN`。
道岔阻力功为 `24×逆向数 + 12×(顺向数+菱形交叉数) + 48×交分/三开数`。
基本阻力和风阻分别乘对应区域的累计长度，加上曲线和道岔功，再乘 `0.001` 得到阻力能高。
它使用工况中指定的两种代表速度，不按每个采样点的瞬时速度反复迭代阻力。

每台启用减速器的制动能高按绑定区段内走过的比例线性累计：
`总制动能高 × 输出比例 × 已通过比例`，出区段后累计至完整值。
该模型按配置的能高分配制动，没有真实控制器闭环响应或车辆碰撞求解。

## 8. 车辆溜放检算

1. 打开“车辆溜放检算”，建立检算方案。
2. 选择纵断面方案和溜放线，输入正值推峰速度。
3. 按释放顺序选择钩车；候选项来自所选纵断面下的计算条件。
4. 点击“执行检算”，程序先保存配置，再请求并刷新结果。
5. 查看速度—距离、时间—距离曲线及设备间隔标注。
6. 可切换曲线标签或展开单张图表；修改输入后重新检算。

检算方案的推峰速度用于按车辆长度计算释放时刻；各钩车的初始动能仍来自所引用工况的峰顶速度。
因此两处峰顶/推峰速度应分别核对，修改其中一处不会自动替代另一处。

速度计算取平面和纵断面 `X` 范围的交集，按空间步长采样，速度降到零后停止后续采样。
运行时间使用 `1 m` 采样步长，以相邻速度的平均值换算区段时间，再加车辆释放时刻。
道岔检算区间当前固定为绑定位置前后各 `10 m`；减速器区间使用其绑定区段。
车辆无法到达某检算区间时，其后的检算数据不再绘制。

相邻间隔计算为 `后车进入时刻 - 前车离开时刻`，单位 s。
负值表示该模型中的设备占用时间重叠；正值仅表示存在时间间隔，还需与实际要求比较。
源码中的 `GetHeadwayCheckResult` 目前只返回空结果对象；当前可用输出是曲线和间隔数据，不能宣称有完整的规范自动合格判定。

若出现“配置保存成功，但刷新结果失败”，表示配置和计算分别处于不同状态。
先修复引用或参数再重算，不要把保存提示当成检算成功。

## 9. 二维与三维仿真

两种仿真使用检算方案，读取纵断面并请求运行时间、速度数据，生成播放轨迹。

- 选择方案，等待轨迹加载后开始播放。
- 使用开始、暂停、结束、前一秒、后一秒、复位按钮控制进度。
- 倍速范围为 `0.25×–3×`；进度滑块定位时刻并显示仿真时钟。
- 二维视图显示车辆位置、顺序、车型和速度。
- 三维视图支持旋转、平移、缩放、复位视角、跟随和显示标签。

没有轨迹时播放操作不可用，需回到检算检查条件及引用。
播放速度只改变演示时间尺度，不改变计算工况或真实运行时间。
三维模型、设备及部分尺寸经过示意处理，不应从画面量取工程尺寸。

## 10. 故障排查与数据维护

| 现象 | 处理方式 |
| --- | --- |
| 实例列表为空 | 核对登录状态、归属及实例启用状态 |
| 无法选择钩车 | 先为所选纵断面建立并保存计算条件 |
| 没有能高曲线 | 检查控制点、选中条件、引用和曲线显示开关 |
| `HUMP_REFERENCE_MISSING` | 按返回的对象类型、标签、编号补建或重新绑定 |
| `HUMP_CALCULATION_DEPENDENCY_MISSING` | 旧依赖错误码，同样按缺失对象处理 |
| 速度曲线提前结束 | 检查能量耗尽、制动设置、坐标公共范围和缺失数据 |
| 仿真无轨迹 | 检查检算方案是否有有效钩车及时间/速度结果 |
| 删除返回冲突 | 先解除依赖；例如仍被检算引用的计算条件不能直接删除 |

改变基础数据可能使旧计算结果失效，重新执行计算与检算后再使用结果。
删除纵断面、溜放线或实例可能清理关联数据；需要保留比较材料时先复制。
报告问题时记录实例/方案名称和编号、操作顺序、参数、页面提示及是否已保存。
