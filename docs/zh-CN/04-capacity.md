# 通过能力分析与计划操作

[文档目录](README.md) · [English](../en/04-capacity.md)

本章说明从已建立的站场方案到作业计划、能力求解、图形调整、报告和仿真的完整流程。功能口径对应 2026-10-11 的仓库实现。过程模板的详细规则见[作业过程编排](05-operation-process.md)。

## 数据层级与准备工作

能力数据按“计算实例 → 站场方案 → 作业计划 → 列车 → 作业 Movement”组织。进路、占用参数、作业过程模板和列车模板属于站场方案；同一方案下的计划共享模板库。复制或删除单个计划不会复制或删除共享模板。

实例管理中的“复制实例”当前只新建实例元信息，不复制下属方案、图形和作业计划，不能当作完整备份。站场方案复制与作业计划复制有各自的数据范围。

在顶部选择启用且有权限的实例，再在各页面选择站场方案。模板编辑不要求存在作业计划；列车计划、求解和仿真需要明确目标计划。切换范围后应核对当前名称。

| 页面 | 用途与完成条件 |
| --- | --- |
| 车站布置图 | 建立并保存几何、节点、线路、设备及轨道电路区段 |
| 进路设计 | 定义起终点、搜索进路、配置进路类型和直接妨碍区段 |
| 计算参数 | 维护各进路、各 Cell 的开始和结束占用偏移 |
| 作业计划 | 编排过程、维护模板和列车、查看计划图及分析 |
| 模型求解 | 生成输入 JSON、选择在线 Agent、提交求解及保存预设 |
| 仿真 | 按已保存计划回放平面或三维站场 |
| 结果分析 | 独立页签仍为占位；实际分析在“作业计划”的子页签 |

圆形按钮可通过悬停或键盘聚焦查看名称。统一分隔条支持拖动、方向键、Shift 加大步长、Home/End 到边界及 Enter/双击复位。EN/中切换界面语言，业务名称不会自动翻译。

## 建立站场与进路

1. 在“实例管理”创建或选择实例。
2. 在“车站布置图”创建方案，导入 DWG 或手工画线，整理拓扑并保存。
3. 检查 Node、Link、Cell 和设备绑定。线段几何相交不代表已经建立节点连接；自动打断、生成节点、近邻节点合并后仍须复核。
4. 在“进路设计”配置起终点，也可按信号机和车挡自动配置。
5. 搜索单条候选或批量生成进路，核对类型、端点、途经节点/线路、道岔、信号机和 Cell。
6. 核对直接妨碍区段，保存进路。停留作业必须有真实停留进路；物理 Link 不能直接替代过程活动的进路候选。

“显示全图”按当前容器等比例缩放并居中，不改坐标。调整窗口或面板后可再次适配。区段名称字体、字号和颜色等方案样式随保存保留，其他二维视图加载同一设置。

在编辑工具栏切换到“完整模式”，可在“拓扑”组设置“合并阈值”。默认值为 10，支持非负小数，单位为图面坐标；0 表示仅合并坐标重合的节点。手动点击“节点合并”和自动拓扑生成均使用当前设置，修改阈值本身不会立即合并节点。此值与对象追踪的“吸附阈值”独立。

点击“精准坐标校正”可在右侧表格逐个填写节点的实际横坐标，支持小数、负数和清空。表格以标签显示各节点绑定的信号机、道岔和车挡，名称前带设备类型（如“道岔9”“信号机X1”），不显示轨道绝缘；坐标栏仅通过“精准坐标校正”按钮手动打开，点击图中的节点或绑定设备不会自动呼出。坐标栏已打开时，选择模式下点击节点或绑定设备，仍会滚动并聚焦对应填写框。实际横坐标单独保存，图面 X 坐标保持不变；输入后点击“保存数据”持久保存，JSON 导入导出也保留该字段。“实际坐标预览”按实际横坐标显示节点、连接轨道及绑定设备，未填写的节点暂用图面 X，并在节点旁用小字显示横坐标。预览中可横向拖动节点，也可继续在表格中修改数值：拖动仅更新实际横坐标，表格、连接轨道及绑定设备同步更新，原图 X/Y 不变。支持撤销、重做，点击“保存数据”保存修改。点击“恢复图面坐标”切回原图并继续其他图形编辑。

拓扑改变会影响设备、区段和既有进路。删除绑定设备的节点时注意同步删除提示；修改后重新检查进路，不能仅凭画面相邻确认连通。

进路的“列车类型”支持多选：接车、发车进路可选“旅客列车”和“货物列车”；其他进路可选“客车（车体）”和“货车（车体）”。在同组内切换进路类别会保留选择，切换到另一组时会改为该组的默认选择。也可清空选择后保存。

新建、自动生成和导入生成的进路默认选中所属组的两种类型。升级后首次启动后端会自动为 SQLite／MySQL 添加 `stationroute.TrainTypes` JSON 数组字段，并为已有进路回填对应默认值；已保存的选择不会被重复迁移覆盖。

## 标定占用参数

每个车站方案可以保存多个计算参数集。在“计算参数”的参数集选择框旁，点击圆形齿轮按钮打开管理对话框，可新建、复制、重命名、删除或设为默认。在对话框中点击某个参数集的“复制计算参数集”图标，选择来源并填写副本名称，会完整复制各进路的公共参数和列车类型专用参数；副本独立保存，后续编辑或删除来源不会影响副本。新建和复制时均可将新参数集设为默认；删除默认参数集前须先指定另一个默认参数集。

选定参数集后选择进路，逐个检查实际途经和直接妨碍 Cell，设置开始、结束占用偏移并保存。参数管理中的“作业时间 (s)”记录进路结束与开始时刻之差，可手工修改；从牵引计算点击“更新计算参数”时，会与区段偏移一起写入当前参数集。作业时间采用独立关系表保存，随参数集复制、删除，不重复存到每个区段。

占用时间图以明显的竖线标出作业开始（0）和作业结束（作业时间）。每个轨道电路只有两个可拖动锚点：开始锚点的绝对时刻为开始偏移，结束锚点的绝对时刻为“作业时间＋结束偏移”；只在两锚点之间绘制一段蓝色圆角矩形。开始偏移量显示在左锚点左侧，结束偏移量显示在右锚点右侧，均直接显示原始偏移值，并与对应锚点同色（左绿右红）。拖动时显示该锚点与对应作业开始或结束时刻之间的同色虚线，松开或取消拖动后隐藏。若结束锚点早于开始锚点，会弹出警告，拖动保留上一个有效位置；已有无效参数仍显示锚点以便修正。未设置作业时间时保留空值，不假设为 0；填入作业时间后显示占用段。占用时间图可拖动端点，也可统一偏移或按进路类型批量设置，操作仅作用于当前参数集。该参数集内列车类型专用参数优先，未设置专用参数的 Cell 使用同一参数集的公共参数。空参数集需要先生成或填写参数，也可直接复制已有参数集。

从列车模板生成计划时，可分别为各模板的列车选择参数集；从作业过程生成时，可分别为各过程选择。单列车新增和编辑也支持选择。未指定参数集时保留空值，作业计划列表不显示默认参数集名称；生成占用和实际计算时使用当前方案默认参数集。指定的参数集已删除或属于其他车站方案时，也使用当前方案默认参数集。修改列车所用参数集会重算其未人工编辑的占用时刻；改变默认参数集、编辑参数或删除参数集不会直接覆盖既有计划中已保存的占用时刻，需要时使用“重新计算占用”。

后端启动时会自动升级 SQLite／MySQL：新增方案内的 `calculationparameterset` 表，为 `stationroutetime` 和 `train` 添加 `CalculationParameterSetID`，将原有参数归入初始默认参数集，已有列车保留未设置状态，计算时使用默认参数集。复制车站方案会同步复制参数集、默认设置及全部参数。

求解时需要同步更新并重启 CapacityAgent（模型版本 2.4.0 或更新），以便按列车所选参数集读取占用参数；后端会拒绝将此类输入交给旧版模型。

```text
Cell 初始开始秒数 = 作业开始秒数 + 开始占用偏移
Cell 初始结束秒数 = 作业结束秒数 + 结束占用偏移
```

偏移可以反映提前锁闭、延迟解锁。正负号、秒与分钟、跨日信息都直接影响冲突判断。独立的“牵引计算”页面可将后端计算得到的完整区段占用转换为这些偏移；在“轨道电路占用明细”中选择参数集后点击“更新计算参数”。

## 创建与维护作业计划

进入“作业计划”，在“列车作业计划”中通过计划管理新建、选择、复制或删除计划。选择列车后展开其作业，维护名称、类型、候选/实际进路、最小时长与起止时刻；保存后再分析。

| 入口 | 数据来源 | 对目标计划的作用 |
| --- | --- | --- |
| 列车模板“自动生成” | 方案共享的传统顺序模板 | 按传统规则重建计划，使用前核对目标 |
| 列车模板“从作业过程生成” | 已保存过程 | 新增共享列车模板，不直接生成列车 |
| 列车作业计划“从作业过程生成” | 多个已保存过程及各自数量 | 向当前计划追加完整列车及独立过程快照 |
| 中观图“从作业过程新增列车” | 已保存过程、逐活动进路选择 | 预览后追加一列完整过程列车 |
| 中观图“点选新增列车” | 图上的起终点和时刻 | 确认后一次保存列车和全部作业 |
| 导入 CellOccupancy | UTF-8 CSV | 默认新建计划，也可追加当前计划 |

列车列表可按车次、名称、类型搜索，空格分隔的关键词逐项匹配。复选“全选”只选择当前筛选的已保存列车；改变筛选会清空勾选。批量删除作用于选中的整列车及其作业、过程快照，删除前核对数量。

### 导入 CellOccupancy CSV

在列车计划工具栏点击“导入 CellOccupancy”，选择不超过 5 MB、50,000 条占用记录的 UTF-8 CSV，先预览再确认导入。

```csv
TrainID,MovementID,MovementType,CellID,OccupancyStartTime,OccupancyEndTime
C2551,0,Arr,1G,02:09:00,02:14:00
C2551,1,Dw,1G,02:14:00,02:30:00
C2551,2,Dep,1G,02:30:00,02:33:00
```

同一列车、同一 MovementID 的多行是同一作业的不同 Cell，应包含真实占用的全部区段。预览中确认 Cell 对应关系、列车与作业数量，以及复用或新建的进路。新进路必须能在既有站场拓扑中形成路径；已有公共占用参数不兼容时会另建进路。

追加时出现重复列车编号会整批拒绝。预览后文件或相关站场/计划数据发生变化时需重新预览。正式导入在事务中保存新计划、进路及作业，失败整体回滚。

## 占用时刻与保存规则

实际计划的占用以 `movement.CellOccupationsJson` 保存，接口返回 `cellOccupations`。每条记录包含 `cellID、routeID、startSeconds、endSeconds、isInterruptCell`。秒数以计划第零天午夜为基准，支持跨日和小数秒。

生成、导入、求解结果保存都会写入占用数据。旧计划读取时由后端补齐；已保存记录不会每次读取都随公共参数自动变化。修改作业时刻或列车类型时，后端更新未人工调整的占用，保留已明确调整的绝对 Cell 时刻。

“重新推算 Cell 占用时间”使用数据库最新作业时刻、类型、进路和占用参数，重新计算当前计划全部占用。它覆盖人工 Cell 时刻、清除旧作业级偏移及撤销历史；作业本身起止时刻和源过程快照保持不变。整批计算/写入失败会回滚。

修改过程列车的 Movement 或 Cell 不会同步重写其完整过程快照。后续求解继续从快照恢复事件基准、时长范围与候选进路；Cell 覆写仅在相应进路和区段匹配时适用。需要变更过程定义时，编辑源过程并重新生成列车。

## 两种计划图

### 作业计划图

占用甘特图以 Cell 为行、时间为横轴，直接读取后端保存的占用时刻。具名股道对应区段以青绿色和淡绿色背景表示；其他区段使用灰蓝色标记。判断依据是 Cell 的 Link 引用及线路名称。

- 横向拖动方块或两端抓手仅改变该 Cell 的绝对占用时刻，不平移整条作业或其他 Cell。
- 上下拖动停留占用块可换股道。目标 Cell 必须明确对应一个具名股道，且具备真实停留进路及所需关联进路。
- 保存通过带原记录的批量接口进行；并发冲突或写入失败会整体恢复。Esc 可取消当前拖动。
- 自适应、X/Y 缩放和刷新与计算参数及仿真占用图共用交互方式。

### 中观作业计划图

中观图的纵轴是节点/具名股道，显示每项 Movement 的真实起终点和时刻。具名股道可折叠为一行，双击股道名称展开两个端点。显示元素与顺序按计划保存；作业正在使用的节点始终参与显示。

过程列车的细线按保存的事件次序绘制：严格次序为实线，最小间隔为虚线；普通列车按作业顺序衔接。连线可切换直线/折线，线条可按过程、进路类型或列车类型配色。显示作业时刻开关在事件附近标记分钟个位数，秒数不进位。

1. 点选线条可选中多列车，Esc 或空白处清空选择。
2. 拖动开始抓手，默认平移本作业两端及后续作业；拖动结束抓手，默认平移本作业结束及后续作业。这里“后续”按作业记录顺序。
3. 同列车在操作开始时完全重合的抓手默认联动；按住 Ctrl 只改当前端点，键盘方向键可微调。
4. 双击抓手按严格次序的规定间隔对齐相关事件，并沿事件有向关系传播；矛盾时取消整次调整。
5. 停留抓手右键可切换通过/到开；通过变到开默认增加 2 分钟，反向转换对齐到较早时刻。
6. 上下拖动停留线换股道时，过程列车按共锚关系联动相关作业；缺少任一匹配进路则整次取消。时刻保持不变。

图形调整不是完整过程约束求解。检查最小时长、次序和资源冲突后再用于结论。悬停活动线可查看实际占用交集形成的冲突明细，即使关闭冲突高亮也可查看。

批量调整一次保存、一次撤销。Ctrl+Z/Ctrl+Y 的历史最多 20 个动作，换计划、重新打开或外部数据改变会清空；输入框内快捷键由输入框处理。换股道会重算占用，撤销可恢复原进路及人工时刻。

## 求解与饱和计划

启动独立 CapacityAgent 并连接当前服务。浏览器负责提交和展示，Agent 负责通信、调度和资源监控；Worker 子进程调用 `SwitchYard.CapacitySolver` 中的混合整数模型与 OR-Tools，优先使用 SCIP，不可用时尝试 CBC。

1. 在“模型求解”选择站场方案与计划，点击“生成输入”，核对 JSON 的计划范围、列车、候选进路及偏移。
2. 选择在线、有权限且有空闲任务槽的 Agent，选择 `station-capacity-v1`。
3. 设置左右时间容差、时限、线程数和目标，提交并观察任务状态。
4. 检查结果 `hasSolution` 与 `status`，下载需要保留的结果 JSON。任务完成不保证有可行解。
5. 保存求解预设；在“作业计划”顶部选择预设并点击“生成饱和计划”，将通过校验的可行解另存为新计划。

当前模型版本为 **2.3.0**。过程地点/锚语义需要 2.2.0，严格等式次序需要 2.3.0，小数秒占用需要至少 2.1.0。混合这些功能时统一使用当前 2.3.0 Agent。输入 JSON 的 `minimumModelVersion` 在含小数秒偏移时可能显示 2.1.0，但服务端派发前还会读取完整过程与严格次序，按较高的 2.2.0/2.3.0 门槛校验，不能只看该字段判断兼容性。

默认设置为左右容差各 50,400 秒、时限 3,600 秒、12 线程、`min-end-time`。实际线程数还受 Agent 每任务 CPU 配额限制。求解目标分别为：

| 目标值 | 最小化内容 |
| --- | --- |
| `min-end-time` | 全部作业结束时刻之和 |
| `min-duration` | 全部作业持续时间之和 |
| `min-start-and-end` | 全部作业开始和结束时刻之和 |

普通列车使用相邻作业的顺序与进路连接约束，作业变量受一天范围限制；过程列车使用事件图、时长上下界、固定事件、严格/最小次序、共享地点及锚，范围最多七天。不同列车使用同一 Cell 时必须错开占用；当前该互斥逻辑跳过同一列车的作业组合，并非同车内部所有资源冲突的检查器。

求解任务、原始输入、进度及结果保存在能力数据库的 `capacitysolvejob` 表中，首次使用时自动建表。关闭、刷新网页或切换实例不会停止后台求解。重新进入“模型求解”后，任务管理列表会自动加载并优先显示进行中的任务；可筛选、分页、进入任意历史任务、查看原始输入及下载结果。普通用户仅管理自己的任务，管理员可管理全部任务；无需选择实例也可进入任务管理。

任务可请求取消，状态先变为“取消中”，待 CapacityAgent 停止 Worker 并确认后才变为“已取消”并释放槽位。代理离线时保留取消请求，重连或上报状态时再次发送。已结束任务可使用原始输入重试（创建新任务并保留旧记录），也可删除任务记录、输入和结果；删除记录不删除已经生成的作业计划。取消功能需要同步更新 CapacityAgent。

API 服务重启后会恢复任务记录。仍在运行的代理重连后继续回传进度和结果；暂时无法回传的结果在代理进程中保留至服务确认接收。若代理进程已重启且任务不再存在，重连时会将任务标记为失败，供用户重试。API 与 CapacityAgent 都需要持续运行，任务不会在关机后自行执行；当前协调方式面向单个 API 服务进程。

普通求解结果不自动更新计划。饱和计划保存会创建新计划，保留求解后的活动时刻、实际进路、Cell 占用及过程快照；源计划保持原样，同一任务重复回传不会重复生成计划。它对既有列车求解，不自动增发列车寻找最大开行数量。

结果中的 `totalOccupationTimeSeconds` 实际取所有占用结束时刻的最大值；`capacityValue = 列车数 × 64800 ÷ 最大占用结束秒数`，分母非正时为 0。该值受计划时间原点影响，不能当作全站最大能力或与下述瓶颈口径混用。

## 能力分析与报告

在“作业计划”中查看占用时间表、瓶颈分析和分类汇总。先统一总统计时间 `T` 与空费系数 `α`，刷新或计算后核对结果。

```text
K(Cell) = 非固定作业占用总秒数 / [(1 − α) × (T − 固定作业占用总秒数)]
进路瓶颈 = 该进路相关区段中 K 最大的区段
进路能力估算 = 进路作业次数 / 瓶颈 K
```

这是对各作业占用时长求和的统计口径，不是时间区间去重后的实际忙碌比例。没有有效分母或利用率时不应把空结果解释为无限能力。分类汇总按关联进路聚合；进路重复归属不同分类时不能再简单相加作为全站总能力。

分析快照及显示设置可保存；修改计划后重新计算，注意区分历史快照和当前计划。中观图工具栏提供 Word 能力报告导出，内容涵盖过程、计划图、占用、瓶颈和分类汇总，保留当前图形配置。报告使用完整提供的数据，不受列表搜索或选中列车限制；历史快照会标注来源。目前报告正文为中文，切换英文界面不会自动生成英文报告。

## 平面与三维仿真

进入“仿真”选择方案、计划和列车。平面/3D 切换共享进度、速度、作业序列、甘特图及单列车/全站范围；离开页签时暂停。默认播放速度为 60 倍，可播放、暂停、复位或拖动时间滑块。

同时进行的多个活动分别高亮；接车为红、发车为蓝、机车为绿、调车为黄。真实停留进路按原计划停留时刻显示，列车在股道中央静止，提前办理的发车进路可同时显示。3D 提供车型、显示比例、标签和占用选项。

回放用于观察已有时序和路径，不自动求解或修复冲突。显示异常时先检查计划、真实进路、Cell 时刻、拓扑和节点，再刷新。

## 牵引计算

本节对应 2026-10-25 的实现。在通过能力工作区选择“牵引计算”，沿用当前实例及站场方案，选择已保存的进路。接车在终点停车，发车从起点静止启动，通过作业可选择一条首尾相连的接续进路，连续展开两条进路。调车使用原进路范围，不设置入口前制动段或一离去，起终点期望速度默认均为 0，且均可修改。起终点速度是期望上限，实际值可因车辆/线路限速、制动、牵引及停车条件降低；运行摘要显示实际起终点速度。

页面顶部使用带标签的小号车站与进路选择框，运行摘要单行显示。摘要、速度位置曲线和占用时间图共同填满工作区；拖动两张图之间的直线可调整各自高度，也可聚焦分隔线后用上下方向键调整，双击恢复均分。各区域内部独立滚动；点击顶部“轨道电路占用明细”按钮，在对话框中查看轨道电路时刻表；“相对开始占用时间”和“相对结束占用时间”两列预览实际回填的整秒值，未释放区段结束值为 0，无法确定的值显示“—”。接续进路按进路编号区分时间偏移。速度图下方状态条始终保留固定高度，未选中位置时显示占位值。

上方深色图绘制当前线路允许速度、已计算的运行速度，以及进路上的道岔、曲线和信号机。道岔编号前加“岔”，信号机只显示自身名称，钢轨绝缘不在上图标注。横轴标明轨道电路范围和名称。工具栏的“显示站外内容”开关默认开启；关闭后，上下两图隐藏入口前的站外制动段，将站内进路范围铺满横轴，并保留原位置与时刻坐标。切换只影响显示，不触发计算。下方使用同一位置坐标绘制车头、车尾时刻与轨道电路占用范围。区段占用从车头进入持续到车尾离开，之后至区段释放的时间单独绘制为红色矩形，横向与对应区段等宽；释放延时为零或时刻未知时不绘制红色矩形。鼠标移动或方向键可联动检查数值，时刻明细通过按钮打开对话框查看。各类作业终点停车后仍被列车覆盖的区段，在首次停车时刻结束占用，不包含终点停时或释放延迟；物理车尾出清和绝缘释放时刻仍可保持未知。若进路端点仍位于同一轨道电路内部，真实边界在计算范围之外，对应进入或出清时刻保持未知；图中仅显示所覆盖的区段范围。原路立即反向返回的接续进路会被拒绝。

点击允许速度线进入编辑模式，双击限速线新增锚点，新增点先沿用所在区间的限速。拖动锚点调整位置和限速，右键点击锚点打开删除菜单，也可选中后按 Delete 删除。按 Esc 或点击图面其他位置退出编辑，退出后隐藏抓手和菜单；页面不显示新增按钮或位置、速度输入栏。0 m 起点保留且位置固定，限速可改。每点从自身位置起，到下一点之前（末点到进路终点）使用设定限速。编辑曲线会同步线路分段表并自动保存至当前方案、当前进路的数据库记录；不会触发计算，运行速度及占用图保留上次结果，点击“计算”后才更新。尚无结果时也可先编辑限速曲线。

工具栏“计算方案”可选择同一车站的多套参数与结果，选择会保存到数据库。点击旁边的“管理”，可以新建、复制、重命名或删除方案；复制包含参数及已保存的计算结果，新建方案尚无结果。每套方案可包含多条进路结果；各主进路与接续进路组合独立维护列车选择、信号、停车点和线路参数，列车参数定义在整个项目内共用，点击“计算”只覆盖当前进路记录。切换进路会读取它自己的参数和结果。“方案进路结果”列出当前方案内所有进路，支持查看、切换和删除；方案管理显示进路总数和结果数量，复制方案包含全部进路。至少保留一套，最多 100 套；旧数据自动归入“默认计算方案”。

在“方案进路结果”切换到“批量计算”，可搜索、筛选并勾选全部需要计算的站场进路或已有接续组合，包括尚无计算结果的进路。点击行可在右侧逐条编辑列车、作业类型、期望速度、制动段、一离去、信号、线路及停车参数；也可用“统一设置已选进路”选择需要统一应用的参数组。已有进路使用各自参数，新进路采用当前工作区的通用设置及对应作业默认速度。点击“批量计算”后，系统逐条保存参数、计算并保存结果，显示进度与每条状态；失败不影响其余进路，可单独修改、重载或重试失败项。“停止后续计算”会等待当前进路完成，保留已完成结果。批量计算不切换当前工作区进路，轨道电路占用偏移仍通过“更新计算参数”写入目标参数集。

“已有结果”中可勾选已计算且与当前参数一致的记录，选择“计算参数集”，再点击“带入计算参数”，将选中结果的作业时间和轨道电路占用偏移一次带入目标参数集。通过结果同时带入主进路和接续进路。时刻不完整的区段保留原值；所有区段占用时刻都未知时，仅带入已知作业时间。未计算或待计算记录需先计算；所选结果对同一进路给出不同时间时，先提示选择一个对应组合。完成提示包含已写入进路及区段数量，部分保存失败会列出已完成进路并显示错误。

项目内所有车站、计算方案和进路共用一份列车参数库，在“维护项目列车参数”中统一维护，最多 1000 个预设；各进路只选择使用哪组列车。修改列车物理参数后，相关进路的旧结果标记为待计算并保留原曲线；仅重命名不使结果过期。旧的进路列车数据自动合并，相同定义去重，同名不同参数保留为不同版本，各进路原有选择保留。批量计算也引用同一参数库。

右侧“列车参数”可选择短编组客运、长编组客运或货运示例预设，并查看基本参数摘要。点击“维护列车参数”，在同一弹框中新增、修改或删除预设，维护名称、长度、质量、最高速度、回转质量系数 γ，以及牵引、常用制动、阻力三个特性表。γ 直接输入附加比例，例如 0.1 表示有效惯性质量为列车质量的 1.1 倍；可输入范围为 0～2。已有参数自动按 γ 显示，例如原来的 1.08 显示为 0.08，物理含义不变。至少保留一组预设；牵引、制动、阻力三个表均可增删速度—力节点。制动表保留恒定制动力输入，阻力表保留 Davis A/B/C 输入；点击“生成并替换表格”后每 10 km/h 取点到最高速度。计算以表格离散点的线性插值为准，修改生成参数不会自动替换已录入的节点。弹框内编辑为草稿，取消不改变计算；保存后应用选中的预设，点击“计算”才重新计算。预设在整个项目（当前实例）内共用并统一落库，各进路只独立保存列车选择，其他计算参数修改后自动保存；“保存到数据库”用于主动保存或重试。数据库尚无工作区记录时，旧浏览器预设与参数在首次保存成功后一次性迁入；此后以数据库记录为准。三组内置值均为可编辑的示例，不对应实际车型。点击“维护坡度、限速与附加阻力”在另一弹框中编辑线路分段参数，线路编辑即时生效并自动保存到数据库。力单位为 kN，质量为 t，速度为 km/h，阻力为 R=A+Bv+Cv²。牵引速度节点从 0 开始严格递增，力非负且随速度不增，节点间线性插值，超过末节点沿用末行牵引力。信号办理、反应与出清延时均以秒计；时间零点是开始办理进路，车头进入起点的时刻为办理时间加反应时间，车尾通过后再加出清延时。

“维护项目列车参数”提供“下载 Excel 模板”和“导入 Excel”。模板含“牵引特性”“制动特性”“阻力特性”三个 Sheet，A、B 列分别为速度（km/h）和对应力（kN），第 1 行为表头，第 2 行起填写数据。每表须填写 1–128 个点，首速度为 0、速度严格递增，力非负，牵引力不可随速度增大。支持小数、零和空行，公式须先粘贴为数值。选择不超过 2 MB 的 `.xlsx` 文件后自动校验三个表，全部通过才替换当前选中列车的三类特性，保留名称、基本参数和其他列车。错误会指出 Sheet 与行号，原数据保留。导入后可继续编辑，点击“保存到项目”才持久保存；取消不提交。

距离优先使用线路的 lengthM 扩展数据，其次使用文件声明的坐标单位与显示变换；缺少单位信息时需显式启用并校准“米/画板单位”的人工标尺。几何长度按圆弧替换曲线切线长度。标尺初值 1 不表示绘图坐标已经是实际米数。未提供的限速使用可编辑缺省值，未提供的坡度按平坡；各线路段均可覆盖限速和坡度，正坡度表示沿运行方向上坡。设备类型不会自动推导道岔/曲线限速，必须按实际资料录入。

计算采用空间离散、后向制动包络和前向牵引积分，默认步长 2 m，并补入限速、设备及车尾出清边界。牵引与制动力按速度线性插值，力平衡计入二次阻力、坡度及回转质量；坡度按列车均匀质量分布加权。整列驶离低限速区后才允许提速。车尾通过位置 x 的时刻使用车头通过 x+车长的时刻，通过加速度关系反解区间内时间。通过/发车终点外仅为车尾出清按末速延伸，并在假设中提示；起点外沿用首段坡度。模型不含黏着、风阻变化、制动传播/建立过程、信号控车曲线或进路外的实际运行。

页面载入时先读取数据库已有曲线；载入、刷新和编辑参数都不自动计算。点击“计算”后才由后端计算并覆盖原结果。计算或保存失败时保留旧结果并显示原因。选择的连续进路、列车预设与牵引节点、信号参数、停车点、距离设置和分段覆盖均保存到关系数据库。每个牵引计算方案中的每条进路记录保留最近一次完整计算输入和结果，包括速度采样、设备、绝缘时刻、轨道电路占用和警告；刷新直接恢复数据库已有结果，即使参数已改也保留原曲线，并标记“待计算”。运行速度、占用图和导出使用原结果快照，允许速度线显示当前编辑值；只有当前输入与结果一致时可更新占用参数。版本校验和事务避免并发覆盖或半次保存。数据库不存整块 JSON 文档，详见[关系表结构](traction-database.md)。可导出速度曲线 CSV，或含全部参数、进路、假设和时刻明细的 JSON 记录。占用明细对话框中可选择与“计算参数”页共享的参数集，点击“更新计算参数”写入当前进路及接续进路的公共轨道电路占用偏移。接车计算以车头首次进入站内进路起点的时刻为进路开始，以车头首次到达进路末端的时刻为进路结束。各途经轨道电路的开始偏移为最早占用时刻（绿色进路办理矩形起点，即 0 秒）减进路开始时刻，包含办理、反应和接近时间；结束偏移为区段释放时刻减进路结束时刻。各类作业最终停车时仍被列车覆盖的区段，包括末端截断的区段，占用结束采用终点首次停车时刻，结束偏移为该时刻减对应进路结束参考；两者重合时为 0。占用图、总占用时间、摘要、明细及参数回填共用此规则，不包含终点停时或额外释放延迟。发车、通过计算继续使用车头进入区段与进路起点出发的时间差；接续进路在连接点停站时使用停时结束后的出发时刻。参数按整秒保存：开始偏移向下取整，已释放区段的结束偏移向上取整。无法确定占用状态的区段及已有其他区段参数保留；干扰区段沿用计算参数原有默认规则。保存后计算参数页刷新对应参数集与进路。已有作业计划占用和仿真时序不会自动重算。连续进路逐条保存，若部分失败，提示已更新的进路及剩余失败情况，可重试。

接车结果的下方“轨道电路占用时间”图还使用黄色矩形表示接近时间：所有轨道电路统一从车头刚进入整条接车进路的制动距离范围的时刻开始，各自到车头进入该区段的时刻结束。黄色矩形的上边缘对齐，横向对应轨道电路范围，悬停可查看起止时刻和持续秒数。黄色矩形上方依次显示绿色进路办理矩形和灰色反应时间矩形，时长采用该次计算保存的信号参数，三段首尾相接。该显示沿用已保存结果的制动距离与运行曲线，不触发重新计算。

## 常见问题

| 现象 | 处理 |
| --- | --- |
| 空列表或按钮禁用 | 检查实例启用状态、权限和方案/计划选择 |
| 停留候选缺失或换道失败 | 在进路设计建立真实停留进路，检查类型与关联接发/调车进路 |
| 参数已改但占用未变 | 已保存 Cell 时刻不会自动刷新；确认影响后使用重新推算 |
| 拖动后下一次求解恢复旧基准 | 过程快照与 Movement 编辑独立；核对源过程和快照 |
| Agent 不可用 | 检查连接、授权、任务槽、CPU/内存余量和模型版本 |
| 无可行解 | 检查时间容差、时长、严格次序、候选进路、锚和占用偏移 |
| 求解结束但仿真未变 | 普通求解未保存计划；生成饱和计划并选择新计划 |
| 独立结果页待开发 | 使用作业计划内的分析子页签 |
