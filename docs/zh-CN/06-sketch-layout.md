# 布置图设计与作业关系分析

[文档目录](README.md) · [English](../en/06-sketch-layout.md)

“布置图分析”用于绘制设施和作业进路、编排物流作业，并按统一时间范围分析作业关系、占用冲突和交叉点排队。它使用独立布置图方案，不与铁路通过能力模块的 Node、Cell、StationRoute 或求解 Agent 自动互通。本章对应 2026-10-11 实现。

## 一个完整使用流程

1. 登录后打开“布置图分析”，在方案管理新建并命名方案。
2. 在“布置图设计”绘制多边形设施、圆形出入口，使用作业进路连接设施。
3. 配置进路名称、方向和锚点，检查需要分析的交叉位置。
4. 点击“进路交叉”生成独立标记，检查来源进路并保存方案。
5. 在“作业流程设计”新建流程方案，设置方案数量，添加各项作业内容和步骤。
6. 在“布置图形分析”设置全图统一出发时段、SLP 阈值、交叉概率模型和占用时间，点击“保存并分析”。
7. 分别阅读作业对冲突、交叉点概率、排队指标和作业关系，不将它们混为一个概率。

普通用户管理自己的方案，管理员可查看和管理全部方案。方案管理可搜索名称、说明或创建者，并创建、打开、修改信息和删除方案。

## 绘图与编辑

普通模式单击选择、拖动空白平移、滚轮缩放。点击绘图工具进入对应模式，Esc 放弃未完成绘制。

| 操作 | 方法 |
| --- | --- |
| 绘制设施 | 逐点绘制多边形，点击首点或 Enter 闭合 |
| 绘制出入口 | 新建圆形对象，编辑中心和半径 |
| 绘制作业进路 | 从圆心、多边形顶点或边中点开始，空白点击添加锚点，终点连接另一设施 |
| 调整几何 | 拖动设施、顶点、进路锚点；属性栏可直接输入有限坐标 |
| 重命名 | 普通模式双击名称或可重命名对象，Enter 保存、Esc 取消 |
| 添加顶点或锚点 | 双击多边形边添加顶点；Shift+双击进路或属性栏添加锚点 |
| 删除锚点 | 右键锚点或在属性栏删除 |
| 调整面板 | 拖动分隔条，方向键微调，双击复位 |

多边形必须有非零面积、不自交，至少三个有效顶点。作业进路连接两个不同设施，端点绑定真实设施位置；无效坐标/几何会提示并恢复。

属性栏可设置设施填充/边框颜色及进路线条/箭头颜色，采用 `#RRGGBB`，清除后恢复默认。进路方向为正向、反向或双向，旧文档缺少方向时按双向读取。流程选择和后端校验都遵守方向；已有流程使用相反方向时，先调整流程再改变方向。

### 网格与视图

网格默认显示且启用吸附，间距 20，可设 1–500 个画板单位。显示与吸附分别控制；缩小时只稀疏显示网格点，吸附间距不变。新顶点、圆心、锚点及拖动对象遵守吸附，整体拖动保留设施形状。

画布支持负坐标及原 2400×1600 范围之外的图元。“全图”包含设施、进路锚点和可见交叉标记，不裁剪或搬移对象。显示进路名称默认关闭，关闭时仍显示选中进路名称。

曲线显示默认开启，用相切圆弧替换折线转角，默认半径 100；短段会缩小倒角。多边形倒角独立控制，默认开启、半径 150，只对符合条件的直角/钝角倒角，锐角、平角和凹角保留。开关不改原顶点、锚点及绑定端点，但进路当前曲线形状参与几何冲突分析。

网格、颜色、显示选项、标记与文档修改支持撤销/重做并随方案保存；面板宽度只是界面状态。

## 交叉标记是生成时快照

点击“进路交叉”按当前折线/圆角路径计算不同进路交点：公共端点和重合区段不生成标记，同位置交点合并。生成的标记记录参与进路 ID 和当时名称。

**每次生成会整批替换原标记**，重新编号、恢复默认半径 24，清除各交叉点自定义占用时间；无交点时也会清空旧标记。该替换可一次撤销。结果超过 1000 个时拒绝替换并保留原标记。

显示/隐藏不重新计算。拖动标记、修改半径、编辑进路或切换曲线不会自动改写其来源。删除进路后仍保留历史来源名并显示已删除；改名会显示现名和来源记录。修改几何后主动核对，必要时重新生成并重新设置占用时间。

交叉标记不是流程步骤。交叉点概率与排队只读已保存的 `sourceLinks`，分析不会自动补交点。作业内容之间的几何冲突则直接检查当前路径，二者来源不同。

## 编排流程方案与作业内容

每个布局可有多套流程方案，每套方案包含若干独立作业内容。流程方案用于分组与统一数量，不表示顺序执行；所有作业内容均在全图同一出发时段内独立出发。

1. 新建流程方案，设置其统一作业数量。
2. 新增并选中作业内容，在画板依次点击设施追加步骤。
3. 在右侧分别编辑设施停留秒数与进入下一设施的进路走行秒数；多条允许方向的进路可选择。
4. 检查纵向列表中的单次耗时、总耗时和草稿状态；复制或删除所选内容，必要时复制整套方案。
5. 点击顶部“保存方案”。草稿可保存，但分析要求全部方案的每项作业内容至少两处设施。

步骤界面交替显示“设施停留 → 进路走行 → 设施停留”。存储仍按设施步骤记录：`dwellSeconds` 是当前设施停留；`incomingLinkId/travelSeconds` 是到达当前设施之前的独立走行。首步没有来向进路且走行时间为 0，后续步必须有有效连通进路，走行时间大于 0。

截断设施步骤会同时移除其来向进路及后续步骤。删除被流程引用的设施/进路会被拦截，先调整步骤引用。同一进路可重复经过，每次都会累加流量及交叉点通行次数。

统一数量作用于方案内每一项作业内容及其所有步骤。若数量为 10、两项作业各持续 60/90 秒，则各自总耗时为 600/900 秒，全图累计执行 20 次；这不是要求两项作业连续执行 1500 秒。

## 全图分析设置

分析默认合并全部流程方案，不需要选择某一方案。设置保存在根级 `analysisSettings`：

| 参数 | 默认值与范围 |
| --- | --- |
| `horizonSeconds` | 3600 秒，允许 1 秒至 365 天，记为 H |
| `aThreshold/eThreshold/iThreshold` | 0.8/0.5/0.2，满足 1 ≥ A > E > I > 0 |
| `crossingModel` | `poisson-fixed`；另有 `uniform-fixed`、`poisson-exponential` |
| 每交叉点每进路占用覆盖 | 0.01 秒至 365 天；留空为自动 |

自动占用时间为该通道在全部作业中的通行次数加权平均走行时间。展开交叉点设置的是独立交叉区占用时间；“恢复自动”清除覆盖，设施停留时间不进入该服务时间。

修改参数或文档后旧分析失效，重新保存并分析。分析接口读取服务器已保存文档，不接受未保存草稿作为临时分析输入。

## SLP 作业关系

每次相邻设施转移累加方案数量，汇总设施对正反向总作业量。以全图最大设施对总量归一化：

```text
相对作业强度 = 该设施对双向总量 / 全图最大设施对双向总量
正流量按 A/E/I 下限分级，其余正流量为 O，零流量为 U
```

这是本模块可配置的作业量分级，未评价非作业关系和 X 关系。多条连接同一设施对的进路共用一个等级。

“作业关系”页上部是关系表，下部是菱形三角活动关系图，每对设施只出现一次，包括 U。菱形上格显示等级、下格显示双向总量；悬停或键盘聚焦可查看方向流量和相对强度。较大矩阵可滚动，上下分隔条调整高度。

## 作业内容之间的冲突概率

该计算固定各步骤时长，假设每次作业独立、均匀地在 `[0,H]` 出发，允许完成时间超过 H。设施和通道为单容量资源，同向、对向及几何交叉/重叠通道都可能冲突。

设两次作业起点差 `Δ = startB − startA`，占用区间分别为 `[a,b)`、`[c,d)`，则冲突条件为：

```text
a − d < Δ < b − c
```

将所有资源产生的冲突区间合并，再对两个独立均匀分布之差的三角分布积分，避免重复计算同一作业对。不同作业内容有 `n×m` 对，同一作业内容有 `n×(n−1)/2` 对。

展示值是单对作业至少一次冲突概率和期望冲突作业对数。期望对数可相加，但不等于全系统至少一次冲突概率。圆角每段以 24 等分近似；几何交叉通道在整个通行期间互斥，因此是保守占用估计，不是碰撞概率。

## 交叉点通行冲突概率

对已保存标记，汇总来源进路次数 `Nᵢ`，包括重复经过，定义 `λᵢ=Nᵢ/H`，占用时间为 `mᵢ`。同一标记内的不同来源进路视为两两互斥。

总体值 `ΣNᵢPᵢ/ΣNᵢ` 表示随机一次通行与其他参与进路至少发生一次占用重叠的概率，不是全时段概率，也不是排队延误。

令 `Bᵢ=Σⱼ≠ᵢλⱼmⱼ`、`Rᵢ=Σⱼ≠ᵢλⱼ`：

| 模型 | 条件冲突概率与边界 |
| --- | --- |
| 泊松到达、固定占用 | `Pᵢ=1−exp(−Bᵢ−Rᵢmᵢ)` |
| 泊松到达、指数占用 | 输入平均时长，`Pᵢ=1−exp(−Bᵢ)/(1+Rᵢmᵢ)` |
| 均匀到达、固定占用 | 固定次数在 `[0,H]` 独立出发，按下式对条件无冲突概率积分 |

```text
ℓᵢⱼ(u) = min(H,u+mᵢ) − max(0,u−mⱼ)
Pᵢ = 1 − (1/H) ∫₀ᴴ ∏ⱼ≠ᵢ (1−ℓᵢⱼ(u)/H)^Nⱼ du
```

泊松模型使用平稳到达过程，包含时段开始前尚未结束的占用，指数时长对每次到达独立抽取；均匀模型固定次数，从时段起点开始，不包含早于 0 的作业。均匀模型先按给定出发时刻组合概率再积分，处理边界及占用大于 H 的情况。

同一作业重复通过或使用多条参与进路会提示相关性近似。这里只计算跨进路重叠，不计算同进路追踪间隔、调度避让或队列。只有一条来源进路有作业时，跨进路概率为 0，排队仍可能存在。

均匀积分绝对容差 `1e-9`、深度 30，每点最多 100 万、全图 500 万因子求值。未收敛或超限返回 `calculation-limit`，不显示未完成概率。

## 交叉点排队指标

排队另按独占单服务台、先到先服务、无限等候空间计算，包含同进路作业等待。`Wq` 是平均等候秒数，不含服务；`Lq` 是等待队列长度，不含正在通过的作业；`ρ=ΣNᵢmᵢ/H` 是负荷率。

泊松模型使用 M/G/1：

```text
Wq = ΣλᵢE[Sᵢ²] / [2(1−ρ)]
Lq = (Σλᵢ)Wq
固定占用：E[Sᵢ²]=mᵢ²；指数占用：E[Sᵢ²]=2mᵢ²
```

`ρ≥1` 返回 `unstable` 和“无有限稳态”，延误和队长为 null，保留实际负荷率，可超过 100%。不能把 null 解释为 0。

均匀模型从空队列开始，可复现抽样固定次数并进行 FCFS 仿真。Wq 计入全部作业在 H 之后的等待；Lq 仅计算 `[0,H]` 内等待队列面积除以 H，因此不套用稳态 Little 公式。负荷大于 100% 仍可给出有限批次估计。

每点最多 20,000 次通行，64–2048 次重复、200 万仿真事件，全图最多 800 万事件。不满足预算则 `calculation-limit`，保留负荷但不返回延误/队长。展开行提供重复次数和两项估计的标准误。固定种子及来源排序使相同输入可复现。

各交叉点独立评估，不传播上下游延误，不模拟优先权。概率与队列独立报告计算状态，一项超限不掩盖另一项可用结果。

## 结果画板与状态

分析页左右分栏：左侧“冲突分析/作业关系”，右侧共用画板。进路按设施对 AEIOU 等级着色；交叉圆圈按负荷 0–75% 连续色谱填充，75% 及以上固定最高档红色，不透明度 32%。概率数字使用独立 0–100% 色谱。

无数据用灰色，不等于 0%；负荷已知但仿真超限时仍可按负荷着色。分析图显示全部已保存标记，包括设计页隐藏的标记；不修改设计颜色或可见性。

| 状态 | 含义 |
| --- | --- |
| `ready` | 此指标计算完成 |
| `no-traffic` | 没有通行，队列三项指标为 0；概率显示无通行量状态 |
| `missing-sources` | 来源不足两条，无法形成有效交叉分析 |
| `missing-links` | 来源进路已删除，核对/重建标记 |
| `calculation-limit` | 积分或仿真预算不足，减少规模或选择其他模型 |
| `unstable` | 泊松队列负荷不小于 1，无有限稳态 |

## 保存格式与限制

布置图以单个 JSON 文档原子保存至 `sketchlayoutscheme`：根节点有 `facilities、links、crossings、plans、analysisSettings`，流程层级为 `plans[] → chains[] → steps[]`，每方案 `executionMode="parallel"` 并仅保存一个 `quantity`。

PUT 提交 `{ revision, document }`，DELETE 携带 `?revision=N`，版本不符返回 409。重新读取后合并修改，避免覆盖另一窗口。开发默认独立 SQLite `sketchlayout.db`，生产默认独立 MySQL `sketchlayout`；部署须配置该库，不能仅配置通过能力数据库。

旧文档缺少统一分析参数时，所有旧方案参数相同则沿用，否则采用统一默认值；缺少方案数量时采用第一项旧作业内容数量，空方案为 1。缺少方向按双向、缺少执行方式按 parallel 读取。转换保存后持久化，不需要新增业务表。

| 对象或计算 | 上限 |
| --- | --- |
| 请求体 / 方案名称 / 说明 | 8 MiB / 120 字符 / 2000 字符 |
| 设施 / 进路 / 流程方案 / 标记 | 200 / 400 / 50 / 1000 |
| 多边形顶点 / 每进路锚点 | 100 / 24 |
| 每方案作业内容 / 总步骤 / 每内容步骤 | 100 / 1000 / 100 |
| 方案作业数量 | 1–1,000,000 |
| 分析曲线近似线段 | 全图 5000 |
| 作业内容组合 / 占用比较 | 50,000 / 5,000,000 |

作业内容全图分析超过规模会明确失败，不返回遗漏方案的部分结果。几何编辑不会自动建立铁路拓扑或推算走行时间，秒数仍需按业务输入。

## 常见问题与进一步阅读

| 现象 | 处理 |
| --- | --- |
| 相邻设施无法追加步骤 | 检查是否有相连且方向允许的进路 |
| 保存成功但不能分析 | 检查所有方案中的草稿，每项内容至少两处设施 |
| 标记与当前交点不一致 | 标记为独立快照，核对后重新生成，重新填写覆盖时间 |
| 重生标记后参数丢失 | 整批替换会重置属性，可撤销恢复旧标记 |
| 概率低但延误很大 | 两者模型含义不同；排队包括同进路，接近满负荷会放大延误 |
| 负荷超过 100% | 泊松模型无有限稳态；均匀有限批次仍可能计算完整等待 |
| 无法删除设施或进路 | 先移除流程中的相关引用 |
| 保存提示版本冲突 | 重新加载最新 revision，再合并本地修改 |
