# 账号、界面与课程使用指南

[文档目录](README.md) · [English](../en/02-user-guide.md)

本文根据 2026-10-11 的仓库代码说明公共操作、账号权限和课程资源。
驼峰的设计、检算与仿真见[驼峰指南](03-hump.md)；其他模块从文档目录进入。
页面是否打开与接口是否授权是两层检查；能看到页面并不代表能读取或修改业务数据。

## 1. 页面入口与第一次使用

| 页面 | 路径 | 用途 |
| --- | --- | --- |
| 首页 | `/` | 进入各模块、选择语言 |
| 驼峰 | `/hump` | 平面、纵断面、计算、检算与溜放仿真 |
| 通过能力 | `/capacity` | 站场、进路、作业计划、求解与仿真 |
| 能力介绍 | `/capacity-preview` | 浏览能力模块介绍，不是正式求解工作区 |
| 课程 | `/courses` | 教学视频、PDF 和填空练习 |
| 布置图分析 | `/sketchlayout` | 设施、作业流程、关系与冲突分析，需登录 |
| 登录 / 注册 | `/login` / `/createuser` | 建立登录会话或申请账号 |
| 个人信息 | `/userinfo` | 查看资料、修改邮箱和密码 |
| 用户管理 | `/usermanagement` | 管理员管理账号 |
| 驼峰实例管理 | `/hump/instancemanagement` | 管理员管理实例及归属 |
| 无权限 | `/no-permission` | 路由拒绝管理访问时的提示页 |

旧地址 `/usermanager` 会跳转到 `/usermanagement`；`/about` 仍有独立页面。
首页和课程可公开浏览。当前四个课程资源接口均允许匿名访问，课程内容不依赖账号成绩库。
驼峰、能力等业务接口要求有效认证，并按实例归属等规则校验权限。

推荐的首次操作顺序：

1. 由维护人员完成服务器、数据库和模板准备。
2. 注册账号或使用管理员分配的账号登录。
3. 如果出现必须修改密码提示，先完成改密并重新登录。
4. 从首页进入业务模块，确认当前实例、方案和语言。
5. 打开已有实例学习，或复制实例后开展方案比较。
6. 每个编辑区域保存成功后再切换实例、方案或页面。

## 2. 登录、注册和会话

在登录页输入用户名和密码，点击登录，或在密码框按 `Enter`。
用户名、密码错误、账号停用和网络故障应按页面具体提示分别处理。
请求会携带登录令牌；前端有令牌刷新处理，刷新失败时需要重新登录。
请勿将打开过页面或浏览器缓存中的用户名视为仍有有效会话的证明。

自助注册的表单要求如下：

| 输入 | 当前网页要求 |
| --- | --- |
| 用户名 | 3–50 个字符，不能重复 |
| 密码 | 6–30 个字符 |
| 确认密码 | 与密码相同 |
| 邮箱 | 填写时需为合法邮箱格式 |
| 角色 | `User` 或 `Admin` |

选择 `User` 的自助注册账号默认启用。
选择 `Admin` 不会立即获得可用的管理员账号：账号默认停用，需现有管理员启用。
账号创建还会从编号 `001` 的驼峰模板初始化数据；模板缺失或复制失败会导致注册失败。
空数据库并不自带可用模板或首个管理员。相关准备应由维护人员完成。

网页在发送密码前进行 SHA-256 处理，这是现有接口约定。
普通使用者只需输入原始密码，不应自己先计算哈希再填入登录框。
客户端哈希不能替代部署时的 HTTPS；接口对接细节见 API 文档。

## 3. 个人资料与强制改密

右上角用户菜单中的“个人信息”进入 `/userinfo`。
用户名和角色用于识别当前账号；个人页面不提供自行提升角色的操作。
修改邮箱后点击保存，并以成功提示确认提交。

修改密码的步骤：

1. 填写当前密码。
2. 填写 6–30 个字符的新密码；不能与当前密码相同。
3. 再次填写新密码并提交。
4. 改密成功后当前会话退出，使用新密码重新登录。

管理员新建、批量导入和重置密码的账号会被标记为必须修改密码。
登录后路由将其引导至个人信息页；在完成改密前，访问其他页面会再次返回此页。
因此反复跳到个人信息页时，应先查看强制改密提示，不要反复切换模块。
普通自助注册与管理员分配账号的首次登录流程不同。

离开共享电脑前使用用户菜单或个人信息页的退出登录按钮。
关闭某个业务页签不等于退出整个应用的登录状态。

## 4. 管理员的账号维护

用户管理页面和 `/api/Admin/...` 接口要求 `Admin` 角色。
隐藏管理菜单只是界面行为，后端仍独立校验角色。
普通用户直接输入管理地址不会获得管理权限。

管理员可搜索和分页查看账号，并执行以下操作：

- 新建账号，设置角色、邮箱及启用状态。
- 编辑已有账号资料，启用或停用账号。
- 重置密码；用户下次登录需修改临时密码。
- 删除账号；界面及服务端限制删除当前登录账号。
- 下载 Excel 模板、导入账号并查看逐行结果。

批量导入步骤：

1. 在用户管理页下载模板 `user_info_template.xlsx`。
2. 使用模板的首个工作表，保留列标题。
3. 用实际账号替换示例行；示例账号不会被程序自动忽略。
4. 填写 `username`、`password`、`role`、`email`、`isActive`。
5. 上传文件并检查成功数、失败数和每一行的错误。
6. 只对失败行修正后重新导入，避免把已创建账号当成待创建账号。

| 列 | 含义 |
| --- | --- |
| `username` | 必填，服务器检查是否已存在 |
| `password` | 模板内填写原始临时密码，至少 6 位；建议与网页 6–30 位要求一致 |
| `role` | `User` 或 `Admin`；留空按 `User` 处理 |
| `email` | 邮箱，可留空 |
| `isActive` | `1` 启用、`0` 停用；留空默认启用 |

用户名和密码都为空的行会跳过；仅缺其中一项会列为失败。
导入按行报告结果，不应把部分成功当成全部成功。
每个新账号同样需要可复制的默认驼峰模板。

## 5. 按钮、面板和语言

能力、课程等公共工作区采用小圆形操作按钮。
悬停可查看名称，键盘按 `Tab` 可切换焦点；灰色按钮说明选择、权限或加载条件尚未满足。
操作作用范围由当前页签、所选行和相邻字段确定。
驼峰仍使用自己的文字按钮和侧面板；独立站场绘图控件也有自己的工具栏。

有细分隔条的面板可按住拖动改变宽度或高度，也支持键盘：

| 操作 | 结果 |
| --- | --- |
| 左右 / 上下方向键 | 对应方向调整约 10 px |
| `Shift` + 方向键 | 调整约 40 px |
| `Home` / `End` | 设为允许的最小 / 最大尺寸 |
| `Enter` 或双击 | 恢复初始值或页面指定值 |

右侧或底部面板的增减方向与左侧或顶部面板相反。
尺寸受到容器大小和最小尺寸限制，不作为项目数据持久化。
窄窗口中的某些工作区改为上下排列，此时相应分隔条调整高度。
驼峰纵断面通过侧边箭头展开或收起；驼峰平面下方表格不使用公共分隔条。

首页可切换语言；驼峰使用中英文文字入口，能力模块使用 `EN` / `中`。
选择记录在当前浏览器的 `locale` 存储项中；初次访问根据浏览器语言选择。
翻译覆盖界面文本；实例名、设备名、教材原文、用户输入及原始服务器错误不会自动翻译。

## 6. 保存、加载与切换

表格中的修改、图形中的变化和服务器中的已保存数据需要分别确认。
除模块明确说明的自动保存行为外，编辑后都应点击该区域的保存操作。
保存成功后再刷新、加载、切换实例或离开页面。
刷新和加载会读取服务器数据；它们不是保存按钮。
计算成功只证明本次计算返回结果，不代表其他编辑区域均已保存。
在多个浏览器窗口同时编辑同一站场方案时，版本冲突需重新读取并核对修改。

## 7. 学习课程

课程目录按“篇 → 章 → 节”组织，目录宽度可调。
窄窗口中目录放在内容上方，可调整目录高度。

1. 点击篇或章展开目录，在右侧查看重点和难点。
2. 点击小节，查看对应视频、PDF 和填空练习。
3. 多个视频通过视频选项切换；播放、音量、进度由播放器控制。
4. 多个 PDF 先选择文件，再用翻页按钮或邻近页缩略图浏览。
5. 在练习框填入答案，点击评分按钮查看正确数、判定、相似度和参考答案。

PDF 由浏览器逐页渲染后显示，大文件可能需要较长加载时间及更多内存。
视频能否播放取决于文件实际编码和浏览器支持，资源清单中的扩展名不是解码保证。
当前没有课程上传、课件编辑、教师成绩管理或服务器成绩提交功能。
练习状态在页面内处理，刷新后不提供持久恢复。

评分是字符相似度规则：忽略大小写、空格和部分标点，按相邻双字符重合度比较。
相似度 `≥0.9` 为正确，`≥0.5` 且小于 `0.9` 为部分正确，其余为错误；正确数只累计“正确”。
这是辅助自测，不是语义理解评分；同义表达和较短答案可能需要对照参考答案自行判断。

## 8. 教学资源的组织要求

资源由服务器目录提供，配置键为 `Course:VideoDir` 和 `Course:DocDir`。
配置目录下存在 `站场视频` 或 `教学文档` 子目录时，服务器分别优先使用这些子目录。
`DocDir` 未配置时使用 `VideoDir` 作为教学文档根目录的候选。
服务器递归列文件，忽略以 `~$` 开头的临时文件。

推荐结构示例（名称含义及识别标记需保留）：

```text
教学文档/第一篇/学习指导.doc
教学文档/第一篇/第一章/学习指导.doc
教学文档/第一篇/第一章/第一节/课件.pdf
教学文档/第一篇/第一章/第一节/文字教材.doc
教学文档/第一篇/第一章/第一节/习题测试.doc
站场视频/第一篇/第一章/1.1.1.mp4
站场视频/第一篇/第一章/1.1.2.mp4
```

视频文件名以“章号.节号[.片段号]”开头，可识别阿拉伯数字及部分中文数字。
`绪论` 作为特殊篇名处理；其他视频应能解析章节号，且篇目录名与文档对应。
常规小节文档使用“篇/章/节/文件”四层相对路径；更深目录不会自动变成更多教学层级。
篇或章目录中的 PDF 也有兼容路径，会以文件名建立小节。
`学习指导`、`文字教材`、`习题测试` 是当前文件名识别标记，切成英文界面后仍需保留。

服务器枚举 `.pdf`、`.doc`、`.docx`，视频枚举 `.mp4`、`.webm`、`.m4v`、`.mov`、`.avi`、`.mkv`。
但当前 Word 文本提取使用字节解码启发式，并非完整 Word 渲染器；尤其不能保证任意 `.docx` 可解析。
学习指导通过 `重点知识`、`难点知识` 等中文标题定位内容。
习题通过 `答案:` 或 `参考答案:` 分隔题目与答案，答案的续行识别 `(数字)` 或 `（数字）` 开头。
新教材应先用代表性的章节验证显示和题目提取，再批量投放。

## 9. 常见问题与进一步阅读

| 现象 | 检查方法 |
| --- | --- |
| 登录后总返回个人信息 | 完成强制改密，再使用新密码登录 |
| 注册失败或没有默认实例 | 维护人员检查模板 `001` 和账号初始化日志 |
| 看不到实例或提示无权限 | 核对账号、角色、启用状态及实例所属用户 |
| 课程目录为空 | 检查服务配置、目录存在性和资源层级；空清单不一定是登录问题 |
| 文件存在但没有习题或重点 | 检查中文识别标记、答案格式及 Word 字节提取限制 |
| 视频在清单中但无法播放 | 检查文件编码、请求响应和浏览器支持 |
| 英文页面仍有中文 | 区分教材/用户数据与尚未翻译的界面文本 |
| 编辑后重新打开消失 | 核对是否保存成功、实例和方案是否一致 |
