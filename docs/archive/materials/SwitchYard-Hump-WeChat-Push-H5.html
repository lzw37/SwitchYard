SwitchYard.Hump

驼峰纵断面设计辅助工具

调车驼峰是铁路编组站中最关键的设备之一，承担着有改编中转列车的解体任务。但驼峰设计是一个特别小众的领域，计算繁、参数多、方案判断链条长。

我们希望把人从繁重、重复、容易出错的计算工作中解放出来，让使用者把更多精力放在理解方案、比较方案和优化方案上。

为什么需要它？

做驼峰纵断面设计时，最耗人的往往不是“不会算”，而是每改一个坡段、每换一种车辆或运行条件，都要重新整理参数、计算阻力能高、推导速度变化、绘制曲线，再回过头判断方案是否合理。

对刚接触站场与驼峰设计的同学来说，很多精力会被重复计算和表格整理消耗掉。算到最后，可能公式都对了，数值也都带入正确了（但这个可能性不大），却没有真正理解这个方案为什么好、哪里还有进一步提升的空间。

作者曾无数次回忆起半夜在18号楼楼道里，坐在楼梯上 采用古法手工计算 手算半天，算出来减速区是一段上坡的崩溃感……

从“埋头算数据”，走向“抬头看方案”

在这个工具中，纵断面不再只是表格里的坡度、高度和能高。所有与纵断面设计相关的车辆参数、运行条件、能高、速度曲线、时间曲线等要素，都被放到同一个系统中。你可以更快地试方案、改参数、看结果，也更容易理解不同设计因素之间的相互影响。

CORE FEATURES

主要功能

01

溜放线平面展开图的维护

工具提供溜放线至调车场线路的平面展开图展示和维护功能，帮助用户直观构建平面展开图上的设备布置。

02

车辆参数与计算条件配置

可配置车辆类型、质量、迎风面积、推峰速度、溜放速度、风速、温度、空气密度等参数，为不同工况下的能高计算分析提供基础。

03

纵断面设计

支持对驼峰峰顶、驼峰溜放部分的边坡点进行编辑，通过交互式控件调整边坡点高程和水平位置，并可保存不同设计方案，适合教学演示、课程设计和方案初步比选。

04

能高线计算与展示

支持计算并显示初始动能高线、阻力能高线、动能高线和制动能高线。阻力能高还可进一步查看基本阻力、风阻力、道岔阻力、曲线阻力等分项明细。

05

驼峰调速系统的设计

可设置减速器的制动能高、输出比例，用于设计驼峰调速系统，使纵断面设计与调速能力配置形成闭环。

06

驼峰检算

工具可生成车辆速度-距离曲线、时间-距离曲线，辅助判断车辆在溜放过程中的速度变化，以及前后行钩车溜经分路道岔、减速器等关键设备的溜放间隔。

07

车辆溜放与仿真

支持车辆序列、追踪间隔等检算场景，并提供二维及三维溜放仿真视图，便于观察车辆运行过程。

USE CASES

适用场景

该辅助设计工具可用于铁路站场与驼峰相关课程教学、课程设计、设计原理演示、方案初步分析以及学生自主学习。

相比 古法手工计算，它更强调“看得见”的设计过程：参数变化、坡度调整和运行结果可以在同一界面中联动呈现。
