Adapted material:
- secureBrakingBehavior!: backward propagation of speed restrictions using
  the maximum entry speed from which the following target can be reached.
- calculateTractiveEffort: piecewise linear interpolation of a speed/tractive
  effort table, including the final-value behavior above its upper bound.
- forceFromCoefficient, acceleration, distance-step kinematics, and braking
  speed/distance relationships from formulary.jl.

SwitchYard changes:
The typed C# request/result models, distance grid, forward solver, validation,
and integration are new implementation work. The braking model is extended to
combine brake force, train resistance, and track gradient; upstream uses a
specified constant net braking deceleration. Numerical behavior and output are
therefore not claimed to be identical to TrainRuns.jl. This is a scoped
adaptation, not a port of the entire Julia package or its data dependencies.
